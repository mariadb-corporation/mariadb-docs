## About this Release

* MariaDB Server 10.0.6 was released on 18 Nov 2013.
* Please note: Newer releases exist within the MariaDB Server 10.0 release series.
* [What's new in this release?]({release-notes}/community-server/old-releases/10.0/10.0.6)
* MariaDB Server is open source software. [Source code is available.](https://app.gitbook.com/s/SsmexDFPv2xG2OTyO5yV/clients-and-utilities/server-client-software/download/getting-the-mariadb-source-code)
* This release is Beta maturity. Only Stable (GA) releases should be used in production.

## About this Release Series

* This release is part of the MariaDB Server 10.0 release series.
* The MariaDB Server 10.0 release series will be supported until March 2019.
* [What's new in this release series?]({release-notes}/community-server/old-releases/10.0/changes-improvements-in-mariadb-10-0)

## Release History

* The prior release in this series was MariaDB Server 10.0.5, released on 7 Nov 2013.
* This release (MariaDB Server 10.0.6) was released on 18 Nov 2013.
* The next release in this series is MariaDB Server 10.0.7, released on 27 Dec 2013.
* The latest release in this series is MariaDB Server 10.0.38, released on 31 Jan 2019.
