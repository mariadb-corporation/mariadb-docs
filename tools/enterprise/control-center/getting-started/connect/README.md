# Attaching Clusters

Control Center is designed to work with GridGain 8 and GridGain 9 clusters you run in your environment. GridGain 8 ships with Control Center Agent by default.

This section describes how you can attach clusters to Control Center.

{% hint style="warning" %}
Control Center does not monitor Apache Ignite 2, Apache Ignite 3, or GridGain Community Edition clusters. They stay in the cluster list with the data already saved, and the only available action is updating the license to Enterprise or Ultimate Edition.
{% endhint %}
