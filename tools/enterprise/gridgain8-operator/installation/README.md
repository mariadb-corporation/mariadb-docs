# Installation

Helm is the only supported way to install the MariaDB GridGain 8 Kubernetes Operator. There is no pinned-manifest bundle and no OpenShift OperatorHub catalog. The 1.0.0 GA release is available only to MariaDB Enterprise Platform Ultimate customers.
