# Adding Databases

Choose the page that matches what you want to monitor with MariaDB Enterprise Manager:

* [Add a Database without MaxScale](add-database-without-maxscale.md): a single MariaDB Server, or a primary/replica or Galera topology that you define manually.
* [Add a Database with MaxScale](add-database-with-maxscale.md): a primary/replica or Galera topology managed by one or more MaxScale instances. Enterprise Manager discovers the backend servers through MaxScale.
* [Add a GridGain 8 Cluster](add-gridgain-8-cluster.md): GridGain 8 clusters monitored by GridGain Control Center. You connect Enterprise Manager to Control Center once, and its clusters appear in the **Databases** list.

MariaDB Server and MaxScale hosts need the monitoring agent. For package installation steps, see [Agent Installation](agent-installation-t-copy.md).
