These skills cover topics that span several statements, such as the migration from MySQL or vector search.

| Skill | Plugins | What it covers |
| --- | --- | --- |
| `mariadb-features` | `dev`, `sql` | MariaDB-specific features and capabilities that go beyond standard MySQL. |
| `mariadb-query-optimization` | `dev`, `sql` | Best practices for query optimization in MariaDB — indexing strategies, EXPLAIN analysis, pagination, histogram statistics, and MariaDB-specific optimizer settings. |
| `mariadb-system-versioned-tables` | `dev`, `sql` | Best practices for MariaDB system-versioned (temporal) tables — automatic row history built into the database. |
| `mysql-to-mariadb` | `dev`, `sql` | Compatibility guide for developers moving from MySQL to MariaDB, and for developers with MySQL experience working with MariaDB. |
| `mariadb-vector` | `dev`, `sql` | Best practices for using vectors and AI with MariaDB. |
