# Monitoring GridGain 9 Clusters

This section covers monitoring capabilities of Control Center for GridGain 9 clusters. You can start by monitoring each node in isolation, the connection between nodes, or the system as a whole. Control Center features a graphical user interface with flexible, user-configurable dashboards. The dashboards provide a visual presentation of the cluster status.

{% hint style="info" %}
Depending on configuration, [secured clusters](../auth/authorization-permissions.md) might require a cluster-level authentication for some (or all) of the actions.
{% endhint %}
