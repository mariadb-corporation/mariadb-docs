# Attaching Clusters

Control Center is designed to work with Apache Ignite, GridGain 8, and GridGain 9 clusters you run in your environment. GridGain 8 ships with Control Center Agent by default, while for Apache Ignite you will need to download it manually.

This section describes how you can attach clusters to Control Center:

- [GridGain 9](connect-gridgain9-cluster.md)
- [Apache Ignite 3](connect-ignite-3-cluster.md)
- [GridGain 8](connect-gridgain-cluster.md)
- [Apache Ignite 2](connect-ignite-cluster.md)
