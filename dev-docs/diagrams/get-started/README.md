# Get Started diagrams

Edit the diagram in `build.py` (AI, Analytics, Operations, Platform) or `landing-pages.py` (Get Started orientation, AI Tools agent setup), then run `python3 -I build.py` and `python3 -I landing-pages.py`. Each script writes a light and a dark SVG into `get-started/.gitbook/assets/` or `ai-tools/.gitbook/assets/`, so update the page's alt text and caption to match.
