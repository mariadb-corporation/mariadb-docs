# VisuaLeaf

{% hint style="info" %}
VisuaLeaf is third-party software, not developed or maintained by MariaDB and not included with MariaDB Server. MariaDB doesn't test, validate, or support it. Refer to its own documentation and license terms.
{% endhint %}

[VisuaLeaf](https://visualeaf.com/database/mariadb/) is a desktop database client for developers, database administrators, and data teams. It connects to local, self-hosted, and managed MariaDB instances and is available for Windows, macOS, and Linux.

VisuaLeaf provides a visual workspace for common MariaDB tasks, including:

* Browsing and editing tables and data.
* Writing and running SQL with autocomplete and formatting.
* Building `SELECT` queries visually, including joins, filters, grouping, and sorting.
* Generating entity-relationship diagrams from an existing schema.
* Inspecting `EXPLAIN` and `ANALYZE` query plans.
* Managing users, roles, and privileges.
* Creating charts and dashboards from query results.

The SQL and schema tools support MariaDB features such as system-versioned tables, sequences, generated columns, and multiple storage engines.

VisuaLeaf offers a free Community Edition as well as paid editions with additional features.
