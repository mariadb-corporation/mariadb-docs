# Migrating to MariaDB from Oracle

MariaDB can run much of the SQL and PL/SQL code written for Oracle Database. Set [`sql_mode=ORACLE`](../../../variables-and-modes/sql_mode.md#oracle) to enable Oracle-compatible syntax and behavior. For the full list of what Oracle mode changes, see [SQL\_MODE=ORACLE](https://app.gitbook.com/s/aEnK0ZXmUbJzqQrTjFyb/community-server/about/compatibility-and-differences/sql_modeoracle).
