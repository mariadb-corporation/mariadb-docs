# System Variable Differences Between MariaDB 10.8 and MySQL 8.0

The following is a comparison of variables that either appear only in [MariaDB 10.8]({release-notes}/community-server/old-releases/10.8/what-is-mariadb-108) or MySQL 8.0, or have different default settings in [MariaDB 10.8]({release-notes}/community-server/old-releases/10.8/what-is-mariadb-108), and MySQL 8.0. The releases [MariaDB 10.8.3]({release-notes}/community-server/old-releases/10.8/10.8.3) and MySQL 8.0.11, with only default plugins enabled, were used for the comparison. Note that MySQL 8 is an 'evergreen' release, so features may be added or removed in later releases.
