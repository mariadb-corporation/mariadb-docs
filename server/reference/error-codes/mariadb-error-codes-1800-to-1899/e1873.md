# Error 1873: Access denied trying to change to user

| Error Code | SQLSTATE | Error                                   | Description                                      |
| ---------- | -------- | --------------------------------------- | ------------------------------------------------ |
| 1873       | 28000    | ER\_ACCESS\_DENIED\_CHANGE\_USER\_ERROR | Access denied trying to change to user '%s'@'%s' |

Before MariaDB 12.0, the message ends `(using password: %s). Disconnecting`.
