# Error 1127: Can't find symbol in library

| Error Code | SQLSTATE | Error                     | Description                            |
| ---------- | -------- | ------------------------- | -------------------------------------- |
| 1127       | HY000    | ER\_CANT\_FIND\_DL\_ENTRY | Can't find symbol '%s' in library '%s' |

In MariaDB 11.4, the message does not name the library: `Can't find symbol '%s' in library`.
