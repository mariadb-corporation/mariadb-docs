# Error 1118: Row size too large

| Error Code | SQLSTATE | Error                 | Description                                                                                                                                                                                      |
| ---------- | -------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1118       | 42000    | ER\_TOO\_BIG\_ROWSIZE | Row size too large. The maximum row size for the used table type, not counting BLOBs, is %ld. This includes storage overhead, check the manual. You have to change some columns to TEXT or BLOBs |
