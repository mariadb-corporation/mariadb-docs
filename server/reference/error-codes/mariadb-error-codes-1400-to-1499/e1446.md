# Error 1446: The user specified as a definer does not exist

| Error Code | SQLSTATE | Error                  | Description                                                |
| ---------- | -------- | ---------------------- | ---------------------------------------------------------- |
| 1446       | HY000    | ER\_MALFORMED\_DEFINER | The user specified as a definer ('%s'@'%s') does not exist |

Before MariaDB 12.0, the message is `Invalid definer`.
