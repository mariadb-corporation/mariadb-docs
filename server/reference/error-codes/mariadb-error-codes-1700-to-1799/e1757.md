# Error 1757: FULLTEXT index is not supported for partitioned tables

| Error Code | SQLSTATE | Error                                            | Description                                             |
| ---------- | -------- | ------------------------------------------------ | ------------------------------------------------------- |
| 1757       | HY000    | ER\_FULLTEXT\_NOT\_SUPPORTED\_WITH\_PARTITIONING | FULLTEXT index is not supported for partitioned tables. |

## Possible Causes and Solutions

MariaDB no longer raises this error: [partitioned tables](../../../server-usage/partitioning-tables/) can contain [full-text indexes](../../../ha-and-performance/optimization-and-tuning/optimization-and-indexes/full-text-indexes/full-text-index-overview.md). The error code remains defined, but is unused.
