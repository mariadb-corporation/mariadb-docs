# Error 1765: The system variable cannot be set in stored functions or triggers

| Error Code | SQLSTATE | Error                                        | Description                                                           |
| ---------- | -------- | -------------------------------------------- | --------------------------------------------------------------------- |
| 1765       | HY000    | ER\_VARIABLE\_NOT\_SETTABLE\_IN\_SF\_OR\_TRG | The system variable %s cannot be set in stored functions or triggers. |

Before MariaDB 12.3, this error is `ER_VARIABLE_NOT_SETTABLE_IN_SF_OR_TRIGGER`. The message is unchanged.
