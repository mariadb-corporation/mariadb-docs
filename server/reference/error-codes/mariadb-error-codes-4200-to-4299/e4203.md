# Error 4203: Invalid binary vector format

| Error Code | SQLSTATE | Error                               | Description                                                                                                                            |
| ---------- | -------- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 4203       |          | ER\_VECTOR\_BINARY\_FORMAT\_INVALID | Invalid binary vector format. Must use IEEE standard float representation in little-endian format. Use VEC\_FromText() to generate it. |
