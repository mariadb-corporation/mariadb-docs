# Error 1252: All parts of an index must be NOT NULL

| Error Code | SQLSTATE | Error                         | Description                              |
| ---------- | -------- | ----------------------------- | ---------------------------------------- |
| 1252       | 42000    | ER\_INDEX\_CANNOT\_HAVE\_NULL | All parts of a %s index must be NOT NULL |

In MariaDB 11.4, this error is `ER_SPATIAL_CANT_HAVE_NULL` and the message names SPATIAL indexes specifically: `All parts of a SPATIAL index must be NOT NULL`.
