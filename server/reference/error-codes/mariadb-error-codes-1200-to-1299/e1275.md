# Error 1275: User has a password in the old format; please change the password to the new format

| Error Code | SQLSTATE | Error                                  | Description                                                                                   |
| ---------- | -------- | -------------------------------------- | --------------------------------------------------------------------------------------------- |
| 1275       | HY000    | ER\_SERVER\_IS\_IN\_SECURE\_AUTH\_MODE | User '%s'@'%s' has a password in the old format; please change the password to the new format |

Before MariaDB 13.0, the message begins `Server is running in --secure-auth mode, but ...`.
