# Error 1568: Variable can't be set while a transaction is in progress

| Error Code | SQLSTATE | Error                          | Description                                        |
| ---------- | -------- | ------------------------------ | -------------------------------------------------- |
| 1568       | 25001    | ER\_CANT\_SET\_IN\_TRANSACTION | %s can't be set while a transaction is in progress |

Before MariaDB 12.0, this error is `ER_CANT_CHANGE_TX_CHARACTERISTICS` and the message is `Transaction characteristics can't be changed while a transaction is in progress`.
