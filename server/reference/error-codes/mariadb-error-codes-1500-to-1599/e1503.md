# Error 1503: must include all columns in the table's partitioning function

| Error Code | SQLSTATE | Error                                      | Description                                                        |
| ---------- | -------- | ------------------------------------------ | ------------------------------------------------------------------ |
| 1503       | HY000    | ER\_UNIQUE\_KEY\_NEED\_ALL\_FIELDS\_IN\_PF | A %s must include all columns in the table's partitioning function |

## Possible Causes and Solutions

This error occurs when a primary key or unique key on a partitioned table does not include all columns used in the partitioning expression. The `%s` in the message is `PRIMARY KEY` or `UNIQUE INDEX`.

The storage engine checks each unique key one partition at a time. Duplicates in different partitions would go undetected, so every primary or unique key must contain the partitioning columns. See [Partitioning Limitations](../../../server-usage/partitioning-tables/partitioning-limitations.md).

To resolve the error, do one of the following:

* Add the partitioning columns to the key.
* Change the partitioning expression to use columns the key already contains.
* For a unique key (not a primary key), create it with `USING HASH`.
