# Error 1618: option ignored

| Error Code | SQLSTATE | Error                 | Description       |
| ---------- | -------- | --------------------- | ----------------- |
| 1618       | HY000    | WARN\_OPTION\_IGNORED | %s option ignored |

In MariaDB 11.4, the option name is wrapped in angle brackets: `<%s> option ignored`.
