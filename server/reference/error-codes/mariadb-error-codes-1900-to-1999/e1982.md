| ---------- | -------- | ---------------------------------------- | -------------------------------------- |
| 1982       |          | WARN\_INNODB\_PARTITION\_OPTION\_IGNORED | %s option ignored for InnoDB partition |

In MariaDB 11.4, the option name is wrapped in angle brackets: `<%s> option ignored for InnoDB partition`.
