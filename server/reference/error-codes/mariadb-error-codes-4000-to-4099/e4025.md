# Error 4025: CONSTRAINT failed for

| Error Code | SQLSTATE | Error                  | Description                          |
| ---------- | -------- | ---------------------- | ------------------------------------ |
| 4025       | 23000    | ER\_CONSTRAINT\_FAILED | CONSTRAINT `%s` failed for `%s`.`%s` |

## Possible Causes and Solutions

A row violates a [CHECK constraint](../../sql-statements/data-definition/constraint.md#check-constraints) of the table. The message names the constraint. A constraint defined on a column is named after the table and the column, and a constraint defined for the table has its own name:

```
CREATE TABLE ck (qty INT CHECK (qty >= 0), lo INT, hi INT,
  CONSTRAINT range_ok CHECK (lo <= hi), doc JSON);

INSERT INTO ck (qty) VALUES (-1);
ERROR 4025 (23000): CONSTRAINT `ck.qty` failed for `shop`.`ck`

INSERT INTO ck (lo, hi) VALUES (5, 1);
ERROR 4025 (23000): CONSTRAINT `range_ok` failed for `shop`.`ck`
```

A [JSON](../../data-types/string-data-types/json.md) column has a CHECK constraint `json_valid()` that the server adds, so invalid JSON fails with this error too:

```
INSERT INTO ck (doc) VALUES ('{"a":1');
ERROR 4025 (23000): CONSTRAINT `ck.doc` failed for `shop`.`ck`
```

`ALTER TABLE … ADD CONSTRAINT … CHECK` also fails with this error when existing rows violate the new constraint.

A constraint fails only when its condition is false. A condition that is `NULL`, for example because a column is `NULL`, passes. With `INSERT IGNORE` and `UPDATE IGNORE`, the row is skipped with a warning instead.

To solve the error:

* Find the condition with `SHOW CREATE TABLE`, or in the [Information Schema CHECK\_CONSTRAINTS table](../../system-tables/information-schema/information-schema-tables/information-schema-check_constraints-table.md), and correct the data.
* Change or drop the constraint if it's wrong, with `ALTER TABLE … DROP CONSTRAINT`.
* To load data that you will check afterward, you can turn the checks off for the session with [check\_constraint\_checks](../../../ha-and-performance/optimization-and-tuning/system-variables/server-system-variables.md#check_constraint_checks)`=0`. Rows loaded this way aren't checked later.
