# Error 4093: Wrong INSERT into a SEQUENCE. One can only do single table INSERT into a sequence object

| Error Code | SQLSTATE | Error                             | Description                                                                                                                                                                        |
| ---------- | -------- | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 4093       |          | ER\_WRONG\_INSERT\_INTO\_SEQUENCE | Wrong INSERT into a SEQUENCE. One can only do single table INSERT into a sequence object (like with mariadb-dump). If you want to change the SEQUENCE, use ALTER SEQUENCE instead. |
