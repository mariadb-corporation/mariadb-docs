# DECODE\_ORACLE

`DECODE_ORACLE` is a synonym for the [Oracle mode](../../../editions-and-compatibility/comparisons-with-other-databases/sql_modeoracle.md) version of the [DECODE function](../secondary-functions/encryption-hashing-and-compression-functions/decode.md), and is available in all modes.
