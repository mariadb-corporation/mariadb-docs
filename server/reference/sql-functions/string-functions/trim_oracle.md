# TRIM\_ORACLE

`TRIM_ORACLE` is a synonym for the [Oracle mode](../../../editions-and-compatibility/comparisons-with-other-databases/sql_modeoracle.md) version of the [TRIM function](trim.md), and is available in all modes.
