# Worklog

**Worklog has been replaced, please refer to** [**JIRA - project planning and tracking**](jira.md) **for further information**.

Worklog was the tool used to track development of MariaDB.

The MariaDB Worklog was open to everyone; a free account on the developer wiki was required to suggest new tasks and add comments or votes.

If a contributor delivered a working solution that was [accepted into the MariaDB source tree]({general-resources}/community/contributing-participating/contributing-to-the-mariadb-project), they could receive a share of any money pledged for that task; the rest went to MariaDB Corporation Ab for managing the project, code reviews, bug fixes, testing, maintenance, and future updates and merges.

A MariaDB worklog task could also link to the corresponding MySQL worklog task, referenced as #WL.

## Source Code for Worklog

The source code for the Worklog application is hosted on [Launchpad](https://launchpad.net/worklog). The license is GPL.
