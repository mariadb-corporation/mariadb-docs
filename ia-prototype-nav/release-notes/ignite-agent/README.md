# Control Center Agent Release Notes

Control Center Agent is a utility used to connect an Apache Ignite cluster to GridGain Control Center. The latest release is [2.17.0.1]({release-notes}/ignite-agent/2.17.0.1).

For product documentation, see [Attaching an Apache Ignite Cluster](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/getting-started/connect/connect-ignite-cluster).
