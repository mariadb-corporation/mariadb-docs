# Open-Source MCP Server

{% hint style="info" %}
Placeholder page for the navigation prototype. This content does not exist in the documentation yet.
{% endhint %}

The open-source MariaDB MCP server provides a Model Context Protocol interface for querying and managing MariaDB databases. It supports standard SQL operations and vector search over embeddings, for use with AI assistants.

The source and setup instructions are in the [MariaDB/mcp repository](https://github.com/MariaDB/mcp) on GitHub.
