# GridGain 8 Clients and Drivers

GridGain 8 provides a range of clients and drivers so your applications can connect to a cluster and work with its data. Thin clients offer a lightweight binary-protocol connection across several languages, the platform-specific sections cover the .NET and C++ APIs in depth, and the JDBC and ODBC drivers let SQL applications and tools query the cluster with standard SQL.
