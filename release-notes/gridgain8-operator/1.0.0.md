# GridGain 8 Kubernetes Operator 1.0.0 Release Notes

GridGain 8 Kubernetes Operator 1.0.0 is a Stable (GA) release of the 1.x line.

Release 1.0.0 is a GA release.

If you are installing for the first time, follow the [Helm]({tools}/enterprise/gridgain8-operator/installation/helm) documentation. If you are updating the GridGain server version on an existing cluster, follow the [Updates]({tools}/enterprise/gridgain8-operator/updates) page.

## New Features

### Declarative GridGain 8 on Kubernetes

`GridGainCluster` (`gridgain.gridgain.com/v1`) provisions StatefulSets, Services, and configuration for GridGain 8. Helm is the supported install. See the [Introduction]({tools}/enterprise/gridgain8-operator/introduction).

### Configuration Restarts and Version Changes

Mounted configuration changes restart one node at a time. Changing the GridGain server version requires scaling the cluster to zero, then applying the new image. Mixed-version rolling upgrades are not supported.

### Drain Before Voluntary Deletion

The operator waits for partition supply to finish before deleting a pod. Requires GridGain 8.9.37 or newer.

## Platform and Component Versions

This release has been tested with the following versions:

| Platform/Component | Version |
| ------------------ | ------- |
| Kubernetes | 1.35 (`kubeVersion: ">=1.35.0-0"`) |
| OpenShift | 4.22.1 (Helm install; not Red Hat certified, not in OperatorHub) |
| GridGain 8 | 8.9.37 minimum; examples use 8.9.38 |
| Operator image | `docker.mariadb.com/gridgain8-operator:1.0.0` (`linux/amd64`) |

## Compatibility with CNCF-Certified Kubernetes Distributions

Support covers the three latest Kubernetes versions across [CNCF-certified](https://www.cncf.io/training/certification/software-conformance/) distributions. Validation is on upstream Kubernetes. Support extends to certified container platforms based on CNCF conformance, including Amazon EKS, Google Kubernetes Engine (GKE), Azure Kubernetes Service (AKS), VMware Tanzu Kubernetes Grid, and other CNCF-certified distributions. Infrastructure-related issues, such as misconfigured Kubernetes clusters or problems with CSI or CNI drivers, remain outside the scope of support.

## Support

The 1.0.0 GA release is available only to MariaDB Enterprise Platform Ultimate customers. Report problems through MariaDB Enterprise Support.
