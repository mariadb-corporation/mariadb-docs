### New Features <a href="#new-features" id="new-features"></a>

#### GridGain 8 monitoring and Control Center integration

Enterprise Manager shows the GridGain 8 clusters that GridGain Control Center manages, next to MariaDB Server and MaxScale in the databases list. A cluster row shows the Control Center health status (Good, Warning, Bad, or Unknown), and its node rows show each node's online state.

* **Manage GridGain** opens the cluster in Control Center with single sign-on, using Enterprise Manager as the OIDC provider. A user's Control Center access level follows their Enterprise Manager role.
* **Settings > Control Center** (administrators only) configures the connection: the Control Center URL, the SSO client secret, and the path to the Control Center CA certificate. A status indicator shows whether Control Center is reachable.
* **Configure metric exporter** on a GridGain 8 cluster row sets up metric collection. Cluster rows show uptime and the age of the last metric received.
* Enterprise Manager includes GridGain 8 Grafana dashboards and alert rules, with GridGain alerts grouped into sections.

The integration requires GridGain Control Center 2026.2 or later. On the Control Center side, Enterprise Manager must be configured as an OpenID Connect provider named `em`, with role mapping enabled.

#### Unattended installation

<!-- OPEN: Denis says these flags have been in the installer since 26.07, but the 26.07.0 notes don't mention them. New in 26.10 or "now documented"? Flags not verified against install-enterprise-manager.sh — no repo access. -->

The installer can run a fresh installation without prompts, so Enterprise Manager can be provisioned from automation:

* `--unattended` runs the installation without prompting. If `--hostname` and `--port` are not given, the installer uses the detected IP address and the default port.
* `--hostname <host>` sets the host name that Enterprise Manager is reached at.
* `--port <port>` sets the port that Enterprise Manager listens on.

```bash
./install-enterprise-manager.sh --unattended --hostname em.example.com --port 8090
```

Upgrades already run without prompts, reusing the settings from the previous installation.

#### Support for MariaDB Server 12.3 and MaxScale 26.10

Enterprise Manager supports monitoring MariaDB Server 12.3 and MaxScale 26.10, and single sign-on to the MaxScale 26.10 GUI. Galera Cluster alerts are now included.

### Notable Changes <a href="#notable-changes" id="notable-changes"></a>

#### OAuth2 single sign-on settings for MaxScale

Enterprise Manager's OAuth2 provider, used for single sign-on to Grafana and the MaxScale GUI, now accepts only known clients and redirect hosts. After upgrading:

* If a MaxScale uses a custom `admin_oidc_client_id`, add that client ID to `MEMA_OAUTH_CLIENT_IDS` in `.env`.
* If a MaxScale is reached under a different host name than the one it was registered with, add that host to `MEMA_OAUTH_REDIRECT_HOSTS` in `.env`.
