# MariaDB Migrator 1.5.0 Release Notes

{% include "../../.gitbook/includes/unreleased-migrator.md" %}

**Release date:** TBD

MariaDB Migrator 1.5.0 is the first Generally Available (GA) release of the MariaDB tool that automates end-to-end migrations from MySQL to MariaDB.

## Overview

The migrator orchestrates schema migration, data transfer, user and privilege migration, and post-migration validation, driving the standard MariaDB client tools (`mariadb-dump`, the `mariadb` client, and the `mariadb-mtk` data-transfer engine) under a single launcher.

## Key Features

* Four migration modes, selectable interactively or through a configuration file, environment variables, or the command line:
  * Serial Streaming Copy (`one_step`) — offline, for smaller databases and standard maintenance windows
  * Parallel Restartable Streaming Copy (`two_step`) — offline, for larger datasets that need schema-then-parallel data loading
  * Offline Copy (`staged`) — offline, for air-gapped source and target pairs, or pairs that cannot reach each other over the network
  * Replication (`binlog`) — online, for low-downtime cutover through ongoing replication
* Assess & Plan mode, which inspects the source and target, validates connectivity and compatibility, and produces an assessment report and a migration plan without moving data or writing to the target
* Assess + Run mode, which runs an assessment followed by the full migration, with confirmation steps between phases
* Schema, data, user, and privilege migration in a single automated, repeatable, auditable workflow
* Post-migration validation
* Application user migration support
* Configuration through environment variables, configuration files, and command-line flags

## Supported Environments

* **Source:** MySQL 8.0 and 8.4; some modes have version-specific requirements
* **Target:** supported MariaDB Enterprise and Community editions, including MariaDB Cloud, which is validated for the Offline Copy, Parallel Restartable Streaming Copy, and Serial Streaming Copy modes
* **Platforms:** Linux on x86-64 and ARM64, and macOS on ARM64 (Apple silicon); macOS hosts require bash 4.4 or newer

## Availability

MariaDB Migrator is proprietary MariaDB software, provided free to MariaDB customers and partners under approved usage terms. It is distributed from the [MariaDB community downloads page](https://mariadb.com/downloads/community/).
