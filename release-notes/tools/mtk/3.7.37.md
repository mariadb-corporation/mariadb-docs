# mariadb-mtk 3.7.37 Release Notes

{% include "../../.gitbook/includes/unreleased-mtk.md" %}

**Release date:** TBD

mariadb-mtk 3.7.37 is the release of the `mariadb-mtk` data-transfer engine that ships alongside [MariaDB Migrator 1.5.0](../migrator/1.5.0.md). MariaDB Migrator uses `mariadb-mtk` to load data through concurrent sessions in its Parallel Restartable Streaming Copy (`two_step`) mode.

## New Features

* Added the `-mariadb_ssl_key`, `-mariadb_ssl_cert`, and `-mariadb_ssl_ca` options, which configure SSL for connections made through MariaDB Connector/C
* Added the `-tmap` option, which specifies table name mappings on the command line
* Added logging of the tables whose data transfer is in progress, to `sqldata_tables_in_progress.txt`
* Added logging of session connection statistics and details

## Improvements

* Improved performance metrics
* Improved reconnection to MySQL and MariaDB, which is now retried multiple times when a connection error occurs
* Improved error and warning reporting when loading data into MariaDB with `LOAD DATA INFILE`

## Supported Environments

* **Platforms:** Linux on x86-64 and ARM64

## Availability

`mariadb-mtk` is distributed from the [MariaDB community downloads page](https://mariadb.com/downloads/community/).
