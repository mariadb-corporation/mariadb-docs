# MariaDB 10.11.20 Release Notes

{% include "../../.gitbook/includes/unreleased-10-11.md" %}

**Release date:** TBD

[MariaDB 10.11](what-is-mariadb-1011.md) is a stable long term series of MariaDB, [maintained until](https://mariadb.org/about/#maintenance-policy) February 2028. It is an evolution of [MariaDB 10.10](../old-releases/10.10/what-is-mariadb-1010.md) with several entirely new features.

MariaDB 10.11.20 is a _**Stable (GA)**_ release.

{% hint style="success" %}
**For an overview of MariaDB 10.11 see the** [**MariaDB 10.11 Changes & Improvements**](what-is-mariadb-1011.md) **page.**
{% endhint %}

Thanks, and enjoy MariaDB!
