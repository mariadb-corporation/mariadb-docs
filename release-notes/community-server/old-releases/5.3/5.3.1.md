# MariaDB 5.3.1 Release Notes

The most recent release in the [MariaDB 5.3 series](changes-improvements-in-mariadb-5-3.md) is:[**MariaDB 5.3.12**](5.3.12.md)

[Download](https://downloads.askmonty.org/mariadb/5.3.1) |**Release Notes** |[Changelog](../../changelogs/changelogs-mariadb-53-series/mariadb-531-changelog.md) |[Overview of 5.3](changes-improvements-in-mariadb-5-3.md)

**Release date:** 10 Sep 2011

[MariaDB 5.3.1](5.3.1.md) is a [Beta release](../../about/release-criteria.md). In general this means
that there are no known serious bugs, except for those marked as feature
requests. [MariaDB 5.3](changes-improvements-in-mariadb-5-3.md) radically improves performance for subqueries as well as
for joins and single-table queries over large data sets.

**For a detailed description of** [**MariaDB 5.3**](changes-improvements-in-mariadb-5-3.md) **see the** [**What is MariaDB 5.3**](changes-improvements-in-mariadb-5-3.md) **page.**

Compared to [MariaDB 5.3.0](5.3.0.md), [MariaDB 5.3.1](5.3.1.md) is a bug-fix release. It is the second
beta release of the 5.3 series and fixes bugs found in the initial 5.3.0 beta
release.

For a list of every change made in [MariaDB 5.3.1](5.3.1.md), with links to detailed
information on each push, see the [MariaDB 5.3.1 Changelog](../../changelogs/changelogs-mariadb-53-series/mariadb-531-changelog.md). It is worth noting that [MariaDB 5.3](changes-improvements-in-mariadb-5-3.md) is built on [MariaDB 5.2](../5.2/changes-improvements-in-mariadb-5-2.md),[MariaDB 5.1](../5.1/changes-improvements-in-mariadb-5-1.md), and MySQL 5.1.

In most respects [MariaDB](https://app.gitbook.com/o/diTpXxF5WsbHqTReoBsS/s/SsmexDFPv2xG2OTyO5yV) will work exactly as MySQL: all commands,
interfaces, libraries and APIs that exist in MySQL also exist in MariaDB.
