# MaxScale 25.10.4 Release Notes

Release 25.10.4 is a GA release.

**Release Date:** 14 Sep 2026

This document describes the changes in release 25.10.4, when compared to the previous release in the same series.

If you are upgrading from an older major version of MaxScale, please read the [upgrading document](https://app.gitbook.com/s/0pSbu5DcMSW4KwAkUcmX/maxscale-management/deployment/upgrading-maxscale) for this MaxScale version.

For any problems you encounter, please consider submitting a bug report on [our Jira](https://jira.mariadb.org/projects/MXS).

## New Features

* [MXS-6771](https://jira.mariadb.org/browse/MXS-6771) Query Cache | min\_query\_duration
* [MXS-6770](https://jira.mariadb.org/browse/MXS-6770) create a dedicate path variable to isolate where look for .maxctrl.cnf
