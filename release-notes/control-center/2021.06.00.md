# Control Center 2021.06.00 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2021.06.00 release adds a new subscription model for the online version of Gridgain Control Center and UX/bug fixes.

Note: GridGain Control Center 2021.06.01 supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2021.06.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.
