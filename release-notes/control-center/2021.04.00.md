# Control Center 2021.04.00 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2021.04.00 release adds a new top level feature for Team collaboration and cluster sharing, and UX/bug fixes.

Note: GridGain Control Center 2021.03.01 Supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2021.04.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.

### Team Sharing

A new collaboration feature allows you to link multiple user accounts into a Team. Teams can share configuration artifacts such as a cluster connection which they can then use to create custom dashboards, SQL queries, Alerts, etc. Teams owners can assign additional permissions to team members. Additional information about Team capabilities can be found in the [documentation](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/profile/teams).
