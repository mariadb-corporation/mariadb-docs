# Control Center 2025.4 Release Notes

## What's New in This Release

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center release, 2025.4, includes a number of new features, as well as improvements and issue resolutions.

## GridGain 9 Connector Support Scope

GridGain Control Center supports GridGain 9 versions 9.0.17 and later and Apache Ignite 3.0.0.

You need to update [Cloud Connector](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/cloud-connector/connect-cloud-connector) to the latest version (2025.4) to securely connect your GridGain 9 and Apache Ignite 3 clusters to Control Center.

## New Features

### Events Screen

The new **Events** [screen](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/events/events) lets you view, filter, and inspect cluster activity in real time. You can configure which event types to display, apply custom filters, and view detailed event information, making your GridGain 9 and Apache Ignite 3 cluster monitoring and troubleshooting faster and more efficient.

### REST API

Control Center now supports getting detailed reports on cluster health using the [REST API](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/rest-api).

### Prioritize and Cancel Compute Tasks

You can now reprioritize tasks via new context actions available for the **Compute** system view [widget](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/dashboard/configuring-widgets-gg9#compute-system-view).

### Terminate Transactions

You can now terminate active transactions directly from the **Transactions** system view [widget](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/dashboard/configuring-widgets-gg9#transactions-system-view).

### Enhanced Delivery Options: Native Packages & Multi-Arch Docker Images

This release adds more ways to deploy Control Center components:

- **Cloud Connector native packages.** Cloud Connector is now available as Linux packages: `deb` and `rpm`. See the [installation guide](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/cloud-connector/connect-cloud-connector#running-the-connector-with-rpm-or-deb-package) to get started.
- **Multi-architecture Docker images.** All official Docker images are now have support for `arm64` and `amd64` platforms.

## Updating to 2025.4

You can update Control Center to 2025.4 from 2022.2 and more recent versions. To update from older versions, update to [2022.2](2022.2.md) first.

1. If you haven't yet, update to Java 17 or 21.
2. Follow the [update instructions](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/update).

{% hint style="info" %}
The default values of the [TTL](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/configuration#time-to-live-limits) parameters in Control Center 2025.1 are different from those in earlier versions (1 day instead of 7 days). To retain the required TTL values, define them explicitly in the Control Center configuration before version update.
{% endhint %}
