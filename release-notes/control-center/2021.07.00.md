# Control Center 2021.07.00 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2021.07.00 release adds a new subscription model for the online version of Gridgain Control Center and UX/bug fixes.

Note: GridGain Control Center 2021.07.00 supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2021.07.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.

## New Features

### Alerts Update Dynamically

Previously, when Alerts were updated, their status was updated on the backend, but was only updated on the frontend when the page was reloaded. This issue has been fixed. Alerts are now updated in the user interface as soon as user makes updates.

### Clusters can Auto-attach to Global Teams

New properties `account.globalTeam.enabled` and `account.globalTeam.attachCluster` were added. If these options are enabled, a global team is added to Control Center, and all new clusters are automatically attached to it.

You can configure Control Center properties in the `application.yml` file.

### Some Screens are Hidden from Anonymous Users

To streamline UI, some screens were made available to authorized users only. This change only affects features related to billing and subscription plan management.
