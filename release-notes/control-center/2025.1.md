# Control Center 2025.1 Release Notes

## What's New in This Release

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center release, 2025.1, includes a number of new features, as well as improvements and issue resolutions.

## New Features

### Attaching and Initializing Apache Ignite 3 Clusters

You can now [Attach Apache Ignite 3 clusters](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/getting-started/connect/connect-ignite-3-cluster) by running the "add cluster" workflow from the main Nebula toolbar. Once the cluster had been attached, you can [initialize it](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/dashboard/my-cluster#initializing-the-cluster) via the **My cluster** screen.

### Streamlined OpenID Connect

This release streamlines your experience when logging in to Control Center via OpenID in a variety of ways:

- If [OpenID Authenticator](https://www.gridgain.com/docs/latest/administrators-guide/security/authentication#control-center-openid-authentication) is configured on a GridGain 8.9.18 or later cluster, you can use the same credentials for logging in to Control Center and working with the cluster.
- Users can be assigned administrator or user roles, or banned from Control Center by using OpenID attributes.
- A new `account.internal.enabled` allows to disable login via e-mail altogether.

You can see detailed instructions for enabling OpenID Connect in the [OpenID Connect Authentication](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/open-id) documentation.

### Partition Recovery in GridGain 9 Clusters

With this release, you can identify and recover lost table partitions on your GridGain 9 clusters directly from Control Center. In the new **Disaster Recovery** tab of the [Table](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/tables/tables) screen, you can see partition states, and run partition recovery if necessary.

### Running Queries Monitoring on GridGain 9 Clusters

You can now monitor running queries for your GridGain 9 clusters in the [Queries](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/queries/querying-gg9) screen. In the **Running Queries** tab, you can track query performance and see the current query status.

### Cloud Connector

The new [Cloud Connector](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/cloud-connector/connect-cloud-connector) tool can be used to simplify connection to GridGain 9 and Apache Ignite 3 clusters.

Cloud Connector can collect data from your cluster and establishing a connection to Control Center. This can be used in environments where direct access to the cluster from Control Center is not possible.

You can still use the Control Center-initiated connection by using the provided Embedded connector.

## Updating to 2025.1

You can update Control Center to 2025.1 from 2022.2 and more recent versions. To update from older versions, update to [2022.2](2022.2.md) first.

1. If you haven't yet, update to Java 17 or 21.
2. Follow the [update instructions](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/update).

{% hint style="info" %}
The default values of the [TTL](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/configuration#time-to-live-limits) parameters in Control Center 2025.1 are different from those in earlier versions (1 day instead of 7 days). To retain the required TTL values, define them explicitly in the Control Center configuration before version update.
{% endhint %}
