# Control Center 2020.08.00 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2020.08.00 release includes security updates, a new method of cluster registration, additional user administration options, and bug fixes.

Note: GridGain Control Center 2020.08.00 Supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2020.08.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.

### New Method of Cluster Registration

GridGain Control Center no longer uses the Cluster ID to register new clusters. Instead, a token must be generated from the management.sh|bat utility. This token has a single use, will expire after 5 minutes, and can be revoked through the Administration screen.

Please see the updated documentation for more details on how to connect a [GridGain](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/getting-started/connect/connect-gridgain-cluster) and [Ignite](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/getting-started/connect/connect-ignite-cluster) cluster.
