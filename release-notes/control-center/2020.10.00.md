# Control Center 2020.10.00 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2020.10.00 release adds new support for Single Sign On integration through OpenID Connect, new Tracing options,  and bug fixes.

Note: GridGain Control Center 2020.10.00 Supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2020.10.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.

### OpenID Connect Single Sign On Integration

Control Center now can integrate with OpenID Connect compatible identity management systems. This allows Control Center user management to accept logins from identity management systems such as; Google, Okta, MSN, Yahoo, and more.

### New Tracing Instrumentation

Control Center adds support for application tracing of Cache Read and Cache Write operations. Check the Tracing Configuration screen to collect traces and spans for calls to the Cache API.
