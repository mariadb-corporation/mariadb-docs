# Control Center 2025.5.1 Release Notes

## What's New in This Release

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center release, 2025.5.1, is a patch release dedicated to fixing compatibility with GridGain 9.1.17.

## Compatibility Changes

### GridGain 9.1.17 Compatibility

Due to the removal of table-based recovery REST endpoints in GridGain [9.1.17](https://www.gridgain.com/docs/gridgain9/latest/release-notes/9.1.17/release-notes_9.1.17#control-center-incompatibility), Control Center versions 2025.5 and earlier are not compatible with GridGain 9.1.17+ clusters. This Control Center release ensures continued compatibility with the latest GridGain release by switching to new REST endpoints.

Compatibility with GridGain 9.1.16 and earlier is not affected.

#### Recommended Upgrade Process

When upgrading to GridGain 9.1.17 or later, it is recommended to update to Control Center 2025.5.1 first. This ensures that you will be able to monitor your cluster without interruptions or issues with data.

## Updating to 2025.5.1

You can update Control Center to 2025.5.1 from 2022.2 and more recent versions. To update from older versions, update to [2022.2](2022.2.md) first.

1. If you haven't yet, update to Java 17 or 21.
2. Follow the [update instructions](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/update).

{% hint style="info" %}
In Control Center 2025.1, the default [TTL](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/configuration#time-to-live-limits) parameters were reduced from 7 days to 1 day. When upgrading from versions earlier than 2025.1, explicitly set the required TTL values in the Control Center configuration **before version upgrade**.
{% endhint %}

### Updating to 2025 with an External Cluster

If you use an [external](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/external-cluster) GridGain 8 cluster for data storage, ensure that the cluster version is compatible with the internal Control Center client node. For this release, the required version is **8.9.28**.

Follow these steps to perform the update correctly:

1. Stop Control Center.
2. If an external cluster upgrade is required, follow [upgrade instructions](https://www.gridgain.com/docs/gridgain8/latest/installation-guide/upgrades) or enable [rolling upgrade](https://www.gridgain.com/docs/gridgain8/latest/installation-guide/rolling-upgrades).
3. If you haven't yet, update Control Center to Java 17 or 21.
4. Proceed with the standard Control Center [update instructions](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/update).
