# Control Center 2020.11.00 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2020.11.00 release adds a new top level Cache view feature, additional configuration options to increase internal storage capacity, and bug fixes.

Note: GridGain Control Center 2020.11.00 Supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2020.10.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.

### New Cache View

Control Center now includes a new Cache view to give better insight into the status and data distribution across the caches in your cluster. The Cache view makes it easy to view data partitions across nodes and to detect and analyze lost partitions. New actions are available to run rebalance, introspect into configurations, and more
