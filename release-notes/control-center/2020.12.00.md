# Control Center 2020.12.00 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2020.12.00 release adds new security integration with LDAP and Microsoft Active Directory, and bug fixes.

Note: GridGain Control Center 2020.12.00 Supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2020.12.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.

### Support for LDAP and Active Directory

Control Center now supports LDAP and Microsoft Active Directory for user and group management. Instead of using Control Center's internal user management implementation, you can now configure user management based on existing LDAP or Microsoft Active Directory infrastructure.
