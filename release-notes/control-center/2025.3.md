# Control Center 2025.3 Release Notes

## What's New in This Release

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center release, 2025.3, includes a number of new features, as well as improvements and issue resolutions.

## GridGain 9 Connector Support Scope

GridGain Control Center supports GridGain 9 versions 9.0.17 and later and Apache Ignite 3.0.0.

You need to update [Cloud Connector](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/cloud-connector/connect-cloud-connector) to the latest version (2025-3) to securely connect your GridGain 9 and Apache Ignite 3 clusters to Control Center.

## New Features

### Data Center Replication in GridGain 9

With this release, data center replication is now supported for GridGain 9 clusters, providing an extensive overview of your DCR set up, as well as new and improved ways to manage data replication.

## Updating to 2025.3

You can update Control Center to 2025.3 from 2022.2 and more recent versions. To update from older versions, update to [2022.2](2022.2.md) first.

1. If you haven't yet, update to Java 17 or 21.
2. Follow the [update instructions](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/update).

{% hint style="info" %}
The default values of the [TTL](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/configuration#time-to-live-limits) parameters in Control Center 2025.1 are different from those in earlier versions (1 day instead of 7 days). To retain the required TTL values, define them explicitly in the Control Center configuration before version update.
{% endhint %}
