# Control Center 2022.1 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2022.1 release includes a number of UX and bug fixes.

## New Features

### Versioning Update

Control Center releases are now tied to major features being added, or significant issues being fixed. As such, release numbers will no longer be tied to the month of the release and will instead use a `YYYY.N` format, where N is the number of the release in the current year (for example, 2022.1 is the first release of year 2022).

### Compute Grid Monitoring

Support for [Distributed Computing](https://www.gridgain.com/docs/latest/developers-guide/distributed-computing/distributed-computing) was extended with the new Compute screen. With it, you can:

- View running and completed tasks, including extended task information(for example, who started the task and when).
- Identify long-running tasks and the cluster nodes they might be on.
- Dynamically change priority or cancel tasks, individually or in bulk.

### Simplified Feedback

Contacting support has become easier with the new Contact Us form, with Control Center now handling the process of sending e-mails to support from the form. GridGain experts are now also available through Slack and Discord.
