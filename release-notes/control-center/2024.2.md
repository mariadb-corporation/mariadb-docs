# Control Center 2024.2 Release Notes

## What's New in This Release

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center release, 2024.2, includes a number of new features, as well as improvements and issue resolutions.

## New Features

### Dashboard Export and Import

You can now export the current dashboard's definition (including widgets, layout, etc.) as a JSON file. You can then import this JSON file into another environment and have the dashboard whose definition it contains added to your UI, with no need for additional configurations.

The Export and Import operations can be initiated from the context menus in the  [Dashboards screen](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg8/dashboard/dashboard-overview#exporting-and-importing-dashboards).

### New Dashboard Widgets

Two new widgets were added that allow you to monitor additional metrics:

- [SQL query](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg8/dashboard/configuring-widgets#sql-query-widget) - the results of an SQL query, updated at a specified frequency (`SELECT` only)
- [System view](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg8/dashboard/configuring-widgets#system-view-widget) - the selected system view table, updated at a specified frequency

You can add these widgets to any of the predefined or custom dashboards.

### End of Support for Java 11

We no longer support Java 11 in Control Center. Java 17 and 21 are fully supported.

## Updating to 2024.2

You can update Control Center to 2024.2 from 2022.2 and more recent versions. To update from older versions, update to [2022.2](2022.2.md) first.

To update to 2024.2:

1. Update to Java 17 or 21.
2. Create a storage backup of the `work` folder for the Control Center version you are migrating from.

{% hint style="info" %}
Make sure you use the [correct `work` folder](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/install-binary). +
{% endhint %}

1. Enable the migration auto application by setting the `control.repositories.auto-migrate-enabled` parameter to `true` in the `application.properties`.
2. Start the new version of Control Center.

The success or failure of the migration is reflected in the log file.

3. In case of a migration failure:
  - Restore from the backup created in Step 2 and run the Control Center version you tried to update from.
  - Contact us for support: https://gridgain.freshdesk.com/support/login or via email docs@gridgain.com.
