# Control Center 2025.2 Release Notes

## What's New in This Release

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center release, 2025.2, includes a number of new features, as well as improvements and issue resolutions.

## Major Changes

### GridGain 9 Support Scope Change

With this release, GridGain Control Center supports GridGain 9 versions 9.0.17 and later and Apache Ignite 3.0.0. GridGain 9.0.16 and earlier are no longer supported.

You need to update [Cloud Connector](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/cloud-connector/connect-cloud-connector) to the latest version to securely connect your GridGain 9 and Apache Ignite 3 clusters to Control Center.

## New Features

### Code Deployment in GridGain 9

With this release, [code deployment](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/deployment/code-deployment-gg9) is now supported for GridGain 9 clusters, further improving you [computing jobs](https://www.gridgain.com/docs/gridgain9/latest/developers-guide/compute/compute) on GridGain 9 clusters.

### Query Monitoring Improvements

This release features multiple improvements to query monitoring, focused on improving user experience and usability. With the continued effort to support GridGain 9, you can now also monitor currently running queries in the [Queries](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/queries/querying-gg9) screen for you GridGain 9 clusters.

### FST For Specific Data Center

Starting with this release, you can specify the data center ID when you start [Data Center Replication](https://www.gridgain.com/docs/latest/administrators-guide/data-center-replication/introduction) for your GridGain 8 cluster from the [Caches](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg8/caches/caches) screen.

### Monitoring improvements

This release features multiple improvements to monitoring your clusters:

- Attached GridGain 8 clusters now have alerting enabled by default. The `ignite.longJVMPausesCountChange` metric is monitored for never being over 0 milliseconds.
- Cluster health widget now tracks if some nodes in the GridGain 8 cluster are offline, and provides the ID of nodes that are offline.
ignite.longJVMPausesCountChange
- You can now manage what data is collected from GridGain 9 or Apache Ignite 3 clusters from Control Center interface without updating your cluster configuration.

### Strict Table Limitations

You can now set strict limits to the data stored by Control Center on your machine by enabling the `control.repositories.limit.strict-mode.enabled` property to `true`.

## Updating to 2025.2

You can update Control Center to 2025.2 from 2022.2 and more recent versions. To update from older versions, update to [2022.2](2022.2.md) first.

1. If you haven't yet, update to Java 17 or 21.
2. Follow the [update instructions](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/update).

{% hint style="info" %}
The default values of the [TTL](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/configuration#time-to-live-limits) parameters in Control Center 2025.1 are different from those in earlier versions (1 day instead of 7 days). To retain the required TTL values, define them explicitly in the Control Center configuration before version update.
{% endhint %}
