# Control Center 2021.10.00 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2021.10.00 release includes a number of UX and bug fixes.

Note: GridGain Control Center 2021.10.00 supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2021.08.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.

## New Features

### Nebula Cloud Clusters

With [GridGain Nebula](https://www.gridgain.com/docs/nebula/about/overview) you can quickly deploy GridGain clusters in AWS cloud, and have GridGain support team manage them. All Nebula environments are configured for up to 99% availability.

### Code Deployment

With the new Code Deployment feature, you can deploy your code dependencies on the clusters. To do this, you create **Deployment Units** in the Code Deployment screen.

Each deployment unit contains dependencies that are sent to the passed to the cluster and stored in the metastorage. When you deploy your code, all nodes in the cluster will download it at the same time, and make it possible to execute your code much easier.
