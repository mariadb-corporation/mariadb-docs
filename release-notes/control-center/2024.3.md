# Control Center 2024.3 Release Notes

## What's New in This Release

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center release, 2024.3, includes a number of new features, as well as improvements and issue resolutions.

## New Features

The main "news" in this release is the ability to work with [GridGain 9](https://www.gridgain.com/docs/gridgain9/latest/index) clusters via the Control Center UI.

{% hint style="info" %}
If you are not working with GridGain 9 clusters, you can [disable the GridGain 9 connector](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/configuration#gridgain-9-connector-configuration), thus simplifying your environment configuration.
{% endhint %}

### Attaching and Initializing GrigGain 9 Clusters

You can now [attach GridGain 9 clusters](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/getting-started/connect/connect-gridgain9-cluster) by running the "add cluster" workflow from the main Control Center toolbar. Once the cluster had been attached, you can [initialize it](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/dashboard/my-cluster#initializing-the-cluster) via the **My cluster** screen.

### Viewing GridGain 9 Cluster Details

Once a GridGain 9 cluster had been initialized, [its details](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/dashboard/my-cluster#gridgain-9) are shown in the **My cluster** screen.

### Viewing Data Distribution for GridGain 9 Clusters

You can now [view partition distribution](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/tables) among a GridGain 9 cluster's nodes for a specific table or distribution zone. The partition lists include the local partition status, as well as other partition details in a specific node's context.

### Running SQL Queries Against GridGain 9 Clusters

You can now [run SQL queries](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/queries/querying-gg9) against GridGain 9 clusters (including multi-expression queries), as well as view the query results, in the **Queries** screen.

### Parameter-based Filtering for Widgets

You can use the [dashboard parameters](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg8/dashboard/dashboard-overview#parameter-based-filtering-for-widgets) to limit the widget scope to specific:

- Node(s)
- Cache(s)
- Cache group(s)

Each widget collects metrics according to its configuration. This does not change when you apply filtering parameters. What does change is what the widget shows in the UI. For example, if a widget is configured to collect the `CacheSize` metric for caches A, B, and C, and the parameter filters the widget to cache A, the widget will keep collecting `CacheSize` for all three caches, but it will display the data only for cache A.

## Updating to 2024.3

You can update Control Center to 2024.3 from 2022.2 and more recent versions. To update from older versions, update to [2022.2](2022.2.md) first.

1. If you haven't yet, update to Java 17 or 21.
2. Follow the [update instructions](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/update).
