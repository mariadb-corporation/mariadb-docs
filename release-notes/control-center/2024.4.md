# Control Center 2024.4 Release Notes

## What's New in This Release

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center release, 2024.4, includes a number of new features, as well as improvements and issue resolutions.

## New Features

The main "news" in this release is the ability to use more Control Center capabilities when working with [GridGain 9](https://www.gridgain.com/docs/gridgain9/latest/index) clusters.

{% hint style="info" %}
If you are not working with GridGain 9 clusters, you can [disable the GridGain 9 connector](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/configuration#gridgain-9-connector-configuration), thus simplifying your environment configuration.
{% endhint %}

### Viewing GridGain 9 Cluster Metrics

You can now view [metrics from GridGain 9 clusters](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/dashboard/dashboard-overview-gg9) in the Control Center **Dashboard** screen, including the **Default** tab and any custom tabs you add. [Alerts](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/alerting/alerting) can also be configured and monitored now for GridGain 9 clusters.

### Managing Snapshots for GridGain 9 Clusters

You can now [create and manage snapshots](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/snapshots/snapshots-gg9), as well as [view snapshot operation history](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/snapshots/operation-history-gg9), for GridGain 9 clusters in the **Snapshots** screen.

### Managing Users and Adding Users in Bulk

As an admin Control Center user, you can now [edit user details](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/managing-users) in the **User management** tab of the **Admin** screen. You can also create new users in bulk, by importing a CSV file into Control Center.

## Updating to 2024.4

You can update Control Center to 2024.4 from 2022.2 and more recent versions. To update from older versions, update to [2022.2](2022.2.md) first.

1. If you haven't yet, update to Java 17 or 21.
2. Follow the [update instructions](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/update).

{% hint style="info" %}
The default values of the [TTL](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/configuration#time-to-live-limits) parameters in Control Center 2024.4 are different from those in earlier versions (1 day instead of 7 days). To retain the required TTL values, define them explicitly in the Control Center configuration before version update.
{% endhint %}
