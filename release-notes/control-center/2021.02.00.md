# Control Center 2021.02.00 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2021.02.00 release adds improvements for metrics storage efficiency, expanded Help, and bug fixes.

Note: GridGain Control Center 2021.02.00 Supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2020.12.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.

### Improved Metrics Storage

By default Control Center collects all possible metrics from a cluster regardless of whether they are used or not. For a particularly active cluster, this can increase the metrics storage requirements unnecessarily. A new configuration is available to only collect metrics that are currently used in Dashboard screens and Alert configurations. This will greatly reduce the storage requirements for metrics.

### Expanded Help

New links are now available for useful Help information including links to Documentation, Tutorials, Webinars/Meetups, and more.

### Additional Details for Long Running Queries and Query Statistics

New statistics are now tracked for analyzing long running SQL queries and query performance screens. When analyzing a query, information about the query configuration will also be shown such as specific parameters and attributes included in the query (if the query was parameterized), query join configuration information, whether lazy loading is configured, and more settings. Providing this information can make it easier to understand query conditions when debugging and fine tuning query performance.
