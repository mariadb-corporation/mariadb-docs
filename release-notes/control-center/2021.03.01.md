# Control Center 2021.03.01 Release Notes

## What's New in This Release

### Introduction

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center 2021.03.01 release adds improvements for metrics metrics selection, SQL query export, improvements to display metrics in dashboards, and UX and bug fixes.

Note: GridGain Control Center 2021.03.01 Supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2021.03.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.

### Improved metrics selection

A new interface is available for searching, selecting, and learning about cluster metrics. Individual metrics have been re-categorized to make finding the metric of interest simpler and more intuitive. A simplified view shows the metrics hierarchy and search interface while an advanced view enables wildcard expressions to select multiple metrics at once. This interface is available both from the Dashboard and Alerts screens.

### Query results Export

SQL Query results can now be exported to a file for backup, additional analysis, or use in other tools.

### Dashboard graphs for multiple metrics

Graph widgets can now display multiple metrics in a single graph. This can be useful to compare different metrics simultaneously for specific nodes or caches. Using the new metrics selection UI, select multiple metrics from either the simplified view or the advanced interface. If the metrics use different units, additional y-axes will display with tooltips to clarify the selection.
