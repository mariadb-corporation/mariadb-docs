# Control Center 2026.1 Release Notes

## What's New in This Release

GridGain® Control Center is a comprehensive, customizable cluster management and developer tool for Apache® Ignite™ and GridGain applications. Use Control Center to query data across caches, monitor performance metrics, define and track production alerts, take snapshots for backup and recovery, and collect and analyze API traces. The latest Control Center release, 2026.1, includes a new feature, as well as improvements and issue resolutions.

## GridGain 9 Connector Support Scope

GridGain Control Center supports GridGain 9 versions 9.1.0 and later and Apache Ignite 3.1.0 and later.

You need to update [Cloud Connector](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/cloud-connector/connect-cloud-connector) to the latest version (2026.1) to securely connect your GridGain 9 and Apache Ignite 3 clusters to Control Center.

## New Features

### Data and Schema Import

Control Center now includes a new **Data and Schema Import** feature that allows users to import schemas from external relational databases (including MySQL, PostgreSQL, and MariaDB) via JDBC, or from Apache Iceberg tables via REST and JDBC catalogs. The import process covers connection setup, schema and table selection, GridGain-specific storage configuration (zones, storage profiles, colocation keys), column type mapping, and a final review of the generated scripts before execution. See [Data and Schema Import](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/gg9/data-schema-import/data-schema-import) for details.

## Updating to 2026.1

You can update Control Center to 2026.1 from 2022.2 and more recent versions. To update from older versions, update to [2022.2](2022.2.md) first.

1. If you haven't yet, update to Java 17 or 21.
2. Follow the [update instructions](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/update).

{% hint style="info" %}
In Control Center 2025.1, the default [TTL](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/configuration#time-to-live-limits) parameters were reduced from 7 days to 1 day. When upgrading from versions earlier than 2025.1, explicitly set the required TTL values in the Control Center configuration **before version upgrade**.
{% endhint %}

### Updating to 2026.1 with an External Cluster

An [external](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/admin-guide/external-cluster) GridGain 8 cluster stores Control Center's internal data. It is separate from the clusters connected to Control Center for monitoring and management.

Starting with this release, the external cluster must run GridGain **8.9.32 or newer** to remain compatible with the internal Control Center client node.

This version requirement does not apply to monitored clusters, which can run any supported GridGain 8 version.

Follow these steps to perform the update correctly:

1. Stop Control Center.
2. If an external cluster upgrade is required, follow [upgrade instruction](https://www.gridgain.com/docs/gridgain8/latest/installation-guide/upgrades) or enable [rolling upgrade](https://www.gridgain.com/docs/gridgain8/latest/installation-guide/rolling-upgrades).
3. If you haven't yet, update Control Center to Java 17 or 21.
4. Proceed with the standard Control Center [update instructions](https://app.gitbook.com/s/kuTXWg0NDbRx6XUeYpGD/control-center/installation/update).
