# MariaDB ColumnStore 23.02.23 Release Notes

{% hint style="info" %}

{% endhint %}

**Release date:** 2 Aug 2026

MariaDB ColumnStore 23.02.23 is a [Stable (GA)](../../community-server/about/release-criteria.md) release of MariaDB ColumnStore.
