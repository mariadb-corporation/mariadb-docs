# MariaDB ColumnStore 23.02.25 Release Notes

{% hint style="info" %}
ColumnStore 23.02.25 works with MariaDB Enterprise Server 10.6.
{% endhint %}

**Release date:** 2 Nov 2026

MariaDB ColumnStore 23.02.25 is a [Stable (GA)](../../community-server/about/release-criteria.md) release of MariaDB ColumnStore.

## Fixed security vulnerabilities

* \[MCOL-6666] - Fixed a vulnerability in the Cluster Management API (CMAPI) that let a remote user who could reach the CMAPI port run commands as `root` without authenticating

The bundled Apache Thrift library was updated from 0.24.0 to 0.25.0, which resolves the following vulnerabilities. ColumnStore bundles only the Thrift C++ bindings, so vulnerabilities that affect only other language bindings are not listed.

* [CVE-2026-66055](https://www.cve.org/CVERecord?id=CVE-2026-66055)
* [CVE-2026-82458](https://www.cve.org/CVERecord?id=CVE-2026-82458)
* [CVE-2026-83632](https://www.cve.org/CVERecord?id=CVE-2026-83632)
* [CVE-2026-91135](https://www.cve.org/CVERecord?id=CVE-2026-91135)
* [CVE-2026-93925](https://www.cve.org/CVERecord?id=CVE-2026-93925)
* [CVE-2026-93926](https://www.cve.org/CVERecord?id=CVE-2026-93926)

## Notable changes

* \[[MCOL-6673](https://jira.mariadb.org/browse/MCOL-6673)] - Updated the bundled Apache Thrift to 0.25.0
