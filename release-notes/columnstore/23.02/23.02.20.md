# MariaDB ColumnStore 23.02.20 Release Notes

{% hint style="info" %}
ColumnStore 23.02.20 works with MariaDB Enterprise Server 10.6.
{% endhint %}

**Release date:** 20 Jul 2026

MariaDB ColumnStore 23.02.20 is a [Stable (GA)](../../community-server/about/release-criteria.md) release of MariaDB ColumnStore.

## Fixed security vulnerabilities

The bundled Apache Thrift library was updated from 0.17.0 to 0.23.0, which resolves the following vulnerabilities. ColumnStore bundles only the Thrift C++ bindings, so vulnerabilities that affect only other language bindings are not listed.

* [CVE-2026-41604](https://www.cve.org/CVERecord?id=CVE-2026-41604)
* [CVE-2026-41605](https://www.cve.org/CVERecord?id=CVE-2026-41605)
* [CVE-2026-41606](https://www.cve.org/CVERecord?id=CVE-2026-41606)
* [CVE-2026-41607](https://www.cve.org/CVERecord?id=CVE-2026-41607)
* [CVE-2026-43868](https://www.cve.org/CVERecord?id=CVE-2026-43868)
* [CVE-2026-43869](https://www.cve.org/CVERecord?id=CVE-2026-43869)
* [CVE-2026-43870](https://www.cve.org/CVERecord?id=CVE-2026-43870)

## Notable changes

* \[MCOL-6477] - Updated the bundled Apache Thrift to 0.23.0
* \[[MCOL-6178](https://jira.mariadb.org/browse/MCOL-6178)] - Backported the CMAPI upgrade architecture from ColumnStore 23.10, to make upgrades from 23.02 to later versions smoother
* \[[MCOL-6192](https://jira.mariadb.org/browse/MCOL-6192)] - CMAPI can now start MariaDB Enterprise Server on all nodes of a cluster

## Issues fixed

### Can result in hang or crash

* \[[MCOL-6404](https://jira.mariadb.org/browse/MCOL-6404)] - Table locks could remain held after `mcs_backup_manager.sh dbrm_backup`, blocking later `cpimport` and `caldroppartitions` operations
* \[[MCOL-6438](https://jira.mariadb.org/browse/MCOL-6438)] - PrimProc could crash with `AllowDiskBasedAggregation=Y`

### Can result in data corruption

* \[[MCOL-6434](https://jira.mariadb.org/browse/MCOL-6434)] - Corruption of BRM data after a fatal unrecoverable signal

### Related to memory use

* \[[MCOL-6441](https://jira.mariadb.org/browse/MCOL-6441)] - Incorrect memory accounting

### Other fixes

* \[[MCOL-6292](https://jira.mariadb.org/browse/MCOL-6292)] - CMAPI printed a `pkg_resources` deprecation warning
