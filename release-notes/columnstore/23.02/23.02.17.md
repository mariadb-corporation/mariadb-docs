# MariaDB ColumnStore 23.02.17 Release Notes

## Overview

MariaDB ColumnStore 23.02.17 is a Stable (GA) maintenance release of MariaDB ColumnStore. MariaDB ColumnStore is a columnar storage engine that is included with the MariaDB Enterprise Server.

**Release date:** 19 Dec 2025
