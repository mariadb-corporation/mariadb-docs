# MariaDB ColumnStore 25.10.5 Release Notes

{% hint style="info" %}
ColumnStore 25.10.5 works with MariaDB Enterprise Server 10.6, 11.4, and 11.8.
{% endhint %}

**Release date:** 27 Jun 2026

MariaDB ColumnStore 25.10.5 is a [Stable (GA)](../../community-server/about/release-criteria.md) release of MariaDB ColumnStore.

## Notable changes

* \[[MCOL-6342](https://jira.mariadb.org/browse/MCOL-6342)] - Ubuntu 26.04 support in ColumnStore
* \[[MCOL-6313](https://jira.mariadb.org/browse/MCOL-6313)] - RHEL 9 packages now ship SELinux rules
* \[[MCOL-6178](https://jira.mariadb.org/browse/MCOL-6178)] - Overhauled the upgrade and downgrade architecture
* \[[MCOL-6192](https://jira.mariadb.org/browse/MCOL-6192)] - Upgrades now start MariaDB across the cluster
* \[[MCOL-6410](https://jira.mariadb.org/browse/MCOL-6410)] - Added a cross-engine join credentials precheck to upgrades
* \[[MCOL-4250](https://jira.mariadb.org/browse/MCOL-4250)] - Correlated subqueries in an OUTER JOIN ON clause now report an unsupported-feature error instead of returning wrong results

## Issues fixed

### Can result in hang or crash

* \[[MCOL-6302](https://jira.mariadb.org/browse/MCOL-6302)] - Restart of mcsRebuildEM-rebuilt MCS crashes server and does not restore anything
* \[[MCOL-6316](https://jira.mariadb.org/browse/MCOL-6316)] - Race condition b/w EMIndex read/write ops
* \[[MCOL-6328](https://jira.mariadb.org/browse/MCOL-6328)] - Server crash when aggregate and window function co-exist with expression in PARTITION BY
* \[[MCOL-6336](https://jira.mariadb.org/browse/MCOL-6336)] - DATE\_SUB/DATE\_ADD with INTERVAL NULL crashes with BatchPrimitiveProcessor error instead of returning NULL
* \[[MCOL-6404](https://jira.mariadb.org/browse/MCOL-6404)] - Stuck locks after dbrm\_backup
* \[[MCOL-6407](https://jira.mariadb.org/browse/MCOL-6407)] - Analytical query is crashing in librbo.so after upgrade

### Can return wrong results

* \[[MCOL-4601](https://jira.mariadb.org/browse/MCOL-4601)] - MOD and DIV operators not behaving as InnoDB
* \[[MCOL-4667](https://jira.mariadb.org/browse/MCOL-4667)] - Precision loss on AVG(decimal)
* \[[MCOL-6326](https://jira.mariadb.org/browse/MCOL-6326)] - cpimport rollback fails to clear Casual Partitioning Min/Max metadata, causing MAX() to return 0000-00-00
* \[[MCOL-6327](https://jira.mariadb.org/browse/MCOL-6327)] - parallel\_ces produces N× inflated results for EXISTS/NOT EXISTS with self-join tables
* \[[MCOL-6405](https://jira.mariadb.org/browse/MCOL-6405)] - JSON\_SET and JSON\_REPLACE now behave as they do in the server

### Other fixes

* \[[MCOL-4628](https://jira.mariadb.org/browse/MCOL-4628)] - SET double\_col=decimal\_col returns an error
* \[[MCOL-6173](https://jira.mariadb.org/browse/MCOL-6173)] - FROM\_UNIXTIME function fails with 11.8
* \[[MCOL-6287](https://jira.mariadb.org/browse/MCOL-6287)] - CMAPI failed an invariant check when determining whether storage is shared
* \[[MCOL-6297](https://jira.mariadb.org/browse/MCOL-6297)] - Error 1815 when attempting a cross engine query
* \[[MCOL-6300](https://jira.mariadb.org/browse/MCOL-6300)] - Table functions are now rejected in the ColumnStore execution plan
* \[[MCOL-6309](https://jira.mariadb.org/browse/MCOL-6309)] - boost system dependency isn't available on Ubuntu 26.04 so isn't buildable there
* \[[MCOL-6311](https://jira.mariadb.org/browse/MCOL-6311)] - UPDATE and DELETE with IN subqueries failed on cross-engine and self-joins
* \[[MCOL-6332](https://jira.mariadb.org/browse/MCOL-6332)] - aggregate query with ORDER BY ordinal hits internal error "column is not found in info map"
* \[[MCOL-6333](https://jira.mariadb.org/browse/MCOL-6333)] - CPACK\_RPM\_BUILDREQUIRES to include selinux dependency
