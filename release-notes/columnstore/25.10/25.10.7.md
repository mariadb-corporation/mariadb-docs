# MariaDB ColumnStore 25.10.7 Release Notes

{% hint style="info" %}
ColumnStore 25.10.7 works with MariaDB Enterprise Server 10.6, 11.4, and 11.8.
{% endhint %}

**Release date:** 21 Sep 2026

MariaDB ColumnStore 25.10.7 is a [Stable (GA)](../../community-server/about/release-criteria.md) release of MariaDB ColumnStore.

## Issues fixed

### Can result in hang or crash

* \[[MCOL-6528](https://jira.mariadb.org/browse/MCOL-6528)] - PrimProc could abort on an assertion during disk-based aggregation spill after exceeding the aggregation memory limit
* \[[MCOL-6563](https://jira.mariadb.org/browse/MCOL-6563)] - JSON functions could terminate PrimProc, causing queries to fail with `InetStreamSocket::readToMagic: Remote is closed`
* \[MCOL-6512] - Fixed a potential `SIGSEGV` in `MCSSETPARMS`/`CALSETPARMS` processing

### Related to performance

* \[[MCOL-6435](https://jira.mariadb.org/browse/MCOL-6435)] - Disk joins, which large joins can trigger, now respect memory limits; this prevents out-of-memory errors and the hangs and crashes that follow them

### Notable changes

* \[[MCOL-5283](https://jira.mariadb.org/browse/MCOL-5283)] - Implicit type casting for `VARCHAR`, `TEXT`, `BLOB`, and similar columns is now aligned with the server's behavior
* \[[MCOL-6405](https://jira.mariadb.org/browse/MCOL-6405)] - JSON functions are now stateless, which corrects results returned for JSON functions over more than 8192 rows
* \[[MCOL-6475](https://jira.mariadb.org/browse/MCOL-6475)] - Fixed the return value type of `SYSDATE()`, which caused `ERROR 1292: Incorrect datetime value` in row-by-row operations
* \[[MCOL-6492](https://jira.mariadb.org/browse/MCOL-6492)] - ColumnStore post-install script selected the non-systemd path in headless environments, such as CI runners and containers
