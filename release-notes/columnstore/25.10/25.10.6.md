# MariaDB ColumnStore 25.10.6 Release Notes

{% hint style="info" %}
ColumnStore 25.10.6 works with MariaDB Enterprise Server 10.6, 11.4, and 11.8.
{% endhint %}

{% hint style="warning" %}
ColumnStore does not support Fedora 44 yet. This is fixed in ColumnStore 25.10.7.
{% endhint %}

**Release date:** 25 Aug 2026

MariaDB ColumnStore 25.10.6 is a [Stable (GA)](../../community-server/about/release-criteria.md) release of MariaDB ColumnStore.

## Fixed security vulnerabilities

The bundled Apache Thrift library was updated to 0.23.0, which resolves the following vulnerabilities reported against Apache Thrift:

* [CVE-2025-48431](https://www.cve.org/CVERecord?id=CVE-2025-48431)
* [CVE-2026-41602](https://www.cve.org/CVERecord?id=CVE-2026-41602)
* [CVE-2026-41604](https://www.cve.org/CVERecord?id=CVE-2026-41604)
* [CVE-2026-41605](https://www.cve.org/CVERecord?id=CVE-2026-41605)
* [CVE-2026-41606](https://www.cve.org/CVERecord?id=CVE-2026-41606)
* [CVE-2026-41607](https://www.cve.org/CVERecord?id=CVE-2026-41607)
* [CVE-2026-41636](https://www.cve.org/CVERecord?id=CVE-2026-41636)
* [CVE-2026-43868](https://www.cve.org/CVERecord?id=CVE-2026-43868)
* [CVE-2026-43869](https://www.cve.org/CVERecord?id=CVE-2026-43869)
* [CVE-2026-43870](https://www.cve.org/CVERecord?id=CVE-2026-43870)

## Notable changes

* \[[MCOL-6146](https://jira.mariadb.org/browse/MCOL-6146)] - Added modes 2 and 3 to `CALL columnstore_info.load_from_s3`
* \[[MCOL-6513](https://jira.mariadb.org/browse/MCOL-6513)] - Updated the bundled Apache Thrift to 0.24.0

## Issues fixed

### Can result in hang or crash

* \[[MCOL-6325](https://jira.mariadb.org/browse/MCOL-6325)] - PrimProc Crash: Null pointer dereference in TupleBPS::sendError() via uninitialized SBS msgBpp
* \[[MCOL-6331](https://jira.mariadb.org/browse/MCOL-6331)] - Server crash (signal 11) on INSERT INTO ColumnStore table SELECT FROM JSON\_TABLE with NOT EXISTS subquery
* \[[MCOL-6490](https://jira.mariadb.org/browse/MCOL-6490)] - Stuck queries in case of exception inside TupleBPS::receiveMultiPrimitiveMessages
* \[[MCOL-6491](https://jira.mariadb.org/browse/MCOL-6491)] - Possible SIGSEGV in TupleHashJoinStep::abort

### Can return wrong results

* \[[MCOL-6221](https://jira.mariadb.org/browse/MCOL-6221)] - sec\_to\_time() rounds values in ColumnStore
* \[[MCOL-6405](https://jira.mariadb.org/browse/MCOL-6405)] - JSON functions returned incorrect results with Community Server 12.3
* \[[MCOL-6433](https://jira.mariadb.org/browse/MCOL-6433)] - Wrong results: two SELECT expressions dividing by COUNT(DISTINCT) columns from a joined derived table

### Related to memory use

* \[[MCOL-6432](https://jira.mariadb.org/browse/MCOL-6432)] - Memory leak in anyNullInTheColumn(): RowGroup never freed on ALTER TABLE ... NOT NULL
* \[[MCOL-6441](https://jira.mariadb.org/browse/MCOL-6441)] - Incorrect memory accounting
* \[[MCOL-6442](https://jira.mariadb.org/browse/MCOL-6442)] - cpimport leaks open column segment files when a bulk load aborts

### Other fixes

* \[[MCOL-5891](https://jira.mariadb.org/browse/MCOL-5891)] - logrotate script fails on Ubuntu 24.04
* \[[MCOL-6408](https://jira.mariadb.org/browse/MCOL-6408)] - Queries could hang with Community Server 12.3 because MariaDBHasher lost its hash state
