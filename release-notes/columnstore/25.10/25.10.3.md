# MariaDB ColumnStore 25.10.3 Release Notes

{% hint style="info" %}
ColumnStore 25.10.3 works with MariaDB Enterprise Server 11.4 and 11.8.
{% endhint %}

**Release date:** 4 Feb 2026

MariaDB ColumnStore 25.10.3 is a [Stable (GA)](../../community-server/about/release-criteria.md) release of MariaDB ColumnStore.

## Notable changes

* \[[MCOL-5527](https://jira.mariadb.org/browse/MCOL-5527)] - `mcs status` now also reports MariaDB server status

## Issues fixed

* \[[MCOL-6091](https://jira.mariadb.org/browse/MCOL-6091)] - CMAPI gave DMLProc only 10 seconds to stop gracefully
* \[[MCOL-6238](https://jira.mariadb.org/browse/MCOL-6238)] - Some TPC-H queries failed with the Query Accelerator enabled
* \[[MCOL-6258](https://jira.mariadb.org/browse/MCOL-6258)] - Network interface is not ready when checked by mcs-loadbrm
* \[[MCOL-6259](https://jira.mariadb.org/browse/MCOL-6259)] - Controllernode connection retries can run too fast
