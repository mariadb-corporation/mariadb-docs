# MariaDB ColumnStore 25.10.2 Release Notes

{% hint style="info" %}
ColumnStore 25.10.2 works with MariaDB Enterprise Server 11.4 and 11.8.
{% endhint %}

**Release date:** 11 Dec 2025

MariaDB ColumnStore 25.10.2 is a [Stable (GA)](../../community-server/about/release-criteria.md) release of MariaDB ColumnStore.

## Issues fixed

* \[[MCOL-6218](https://jira.mariadb.org/browse/MCOL-6218)] - The null-safe equal operator now handles string literals correctly in filters
* \[[MCOL-6257](https://jira.mariadb.org/browse/MCOL-6257)] - Host decides that it is a read replica if ModuleIPAddr and pmX\_WriteEngineServer are inconsistent
