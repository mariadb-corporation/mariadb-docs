# Control Center Agent 2.12.0.0 Release Notes

Control Center Agent is a utility used to connect an Apache Ignite cluster to GridGain Control Center.

Note: Control Center Agent 2.12.0.0 is designed to work with Apache Ignite 2.12.0+. If you are using an older version of Apache Ignite, please use the appropriate version of Control Center Agent.

## Improved Security

The safety of information passed to Control Center has been greatly improved.
