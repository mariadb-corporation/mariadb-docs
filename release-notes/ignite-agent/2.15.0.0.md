# Control Center Agent 2.15.0.0 Release Notes

Control Center Agent is a utility used to connect an Apache Ignite cluster to GridGain Control Center.

Note: Control Center Agent 2.15.0.0 is designed to work with Apache Ignite 2.15.0+. If you are using an older version of Apache Ignite, please use the appropriate version of Control Center Agent.

## Java 17 Support

In this version of Control Center Agent, support for Java 17 was added, following the recent implementation of similar support in Apache Ignite.
