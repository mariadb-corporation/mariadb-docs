# Control Center Agent 2.16.0.1 Release Notes

Control Center Agent is a utility used to connect an Apache Ignite cluster to GridGain Control Center.

Note: Control Center Agent 2.16.0.1 is designed to work with Apache Ignite 2.16.0+. If you are using an older version of Apache Ignite, please use the appropriate version of Control Center Agent.

This release fixes a issue with using control script in the Control Center Agent 2.16.0.0.
