# Control Center Agent 2.8.1.2 Release Notes

Control Center Agent is a utility used to connect an Apache Ignite cluster to GridGain Control Center.

Note: GridGain Control Center 2020.08.00 Supports GridGain 8.7.23+. You will need to update your version of GridGain in order to work with Control Center 2020.08.00. Apache Ignite users will need to update their Ignite Agent to 2.8.1.2+.

## New Method of Cluster Registration

GridGain Control Center no longer uses the Cluster ID to register new clusters. Instead, a token must be generated from the management.sh|bat utility. This token has a single use, will expire after 5 minutes, and can be revoked through the Administration screen.

## Updated Maven Artifact ID

If you install the Control Center Agent from Maven, the artifact id has changed to control-center-agent starting in this release. You will need to update your pom.xml dependencies accordingly.
