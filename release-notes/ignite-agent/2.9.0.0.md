# Control Center Agent 2.9.0.0 Release Notes

Control Center Agent is a utility used to connect an Apache Ignite cluster to GridGain Control Center.

Note: Control Center Agent 2.9.0.0 is designed to work with Apache Ignite 2.9.0+. If you are using Apache Ignite 2.8.x, please use Control Center Agent 2.8.x.

## Updated Maven Artifact ID

If you install the Control Center Agent from Maven, the artifact id has changed to control-center-agent starting in this release. You will need to update your pom.xml dependencies accordingly.

## Support for Tracing

Apache Ignite 2.9.0 introduces the ability to collect application traces through OpenCensus. Control Center Agent provides the libraries and configuration needed to start collecting traces from you cluster.
