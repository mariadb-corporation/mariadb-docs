# Control Center Agent 2.11.0.0 Release Notes

Control Center Agent is a utility used to connect an Apache Ignite cluster to GridGain Control Center.

Note: Control Center Agent 2.11.0.0 is designed to work with Apache Ignite 2.11.0+. If you are using Apache Ignite 2.8.x, please use Control Center Agent 2.8.x.

## Improved Security

The safety of information passed to Control Center has been greatly improved.
