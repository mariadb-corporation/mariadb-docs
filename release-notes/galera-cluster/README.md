# Galera Cluster Release Notes

{% hint style="info" %}
MySQL-wsrep, Galera Cluster for MySQL, reached end of life on 30 Sep 2026, and has no further releases. The Galera Replication library continues as part of MariaDB Galera Cluster. To move a Galera Cluster for MySQL deployment, see [Migrating from MySQL to MariaDB Galera Cluster (Node-by-Node In-Place)]({server}/server-management/install-and-upgrade-mariadb/migrating-to-mariadb/moving-from-mysql/migration-from-mysql-to-mariadb-cluster-node-by-node-in-place) and the [end-of-life announcement](https://mariadb.com/resources/blog/upgrade-now-announcing-mysql-galera-cluster-in-place-migration-to-mariadb-galera-cluster/).
{% endhint %}
