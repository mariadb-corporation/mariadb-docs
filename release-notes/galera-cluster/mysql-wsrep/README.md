# MySQL-wsrep Release Notes

{% hint style="warning" %}
Galera Cluster for MySQL reached end of life on 30 Sep 2026, and there are no further MySQL-wsrep releases. The last releases were MySQL-wsrep 8.4.11-26.28 and 8.0.46-26.27. These release notes remain as a record.

To keep receiving updates, migrate to MariaDB Galera Cluster, either [node by node, in place]({server}/server-management/install-and-upgrade-mariadb/migrating-to-mariadb/moving-from-mysql/migration-from-mysql-to-mariadb-cluster-node-by-node-in-place) or [using replication]({server}/server-management/install-and-upgrade-mariadb/migrating-to-mariadb/moving-from-mysql/migration-from-mysql-to-mariadb-cluster-using-replication). For details, see the [end-of-life announcement](https://mariadb.com/resources/blog/upgrade-now-announcing-mysql-galera-cluster-in-place-migration-to-mariadb-galera-cluster/).
{% endhint %}
