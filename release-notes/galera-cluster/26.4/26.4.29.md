# Galera 26.4.29 Release Notes

{% include "../../.gitbook/includes/unreleased-galera.md" %}

**Release Date:** TBD

MariaDB is pleased to announce the release of Galera Replication library 4.29, implementing wsrep API version 26.

The library is available in the package repositories for the Linux distributions that MariaDB Community Server supports. Obtaining packages using a package repository removes the need to download individual files and facilitates the deployment and upgrade of Galera nodes.

## Notable changes

* A truncated or malformed GCS message from a cluster member could cause an out-of-bounds read; these messages are now bounds-checked, and a malformed message is logged and ignored
* If the server was started with an unknown option, it could hang on shutdown, because the wait for SST/IST negotiation was never interrupted

## Known Issues

* In order to install Galera package on RHEL 8, MySQL and MariaDB modules need to be disabled first with `dnf -y module disable mysql mariadb`
