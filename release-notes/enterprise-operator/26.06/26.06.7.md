# MariaDB Enterprise Kubernetes Operator 26.06.7

**Release date**: 21 October 2026

MariaDB Enterprise Kubernetes Operator 26.06.7 is a maintenance release for the 26.06 series. It fixes MaxScale servers that were left outside the monitor.

If you are updating from a previous version, **please follow the** [**UPDATE GUIDE**](https://mariadb.com/docs/tools/enterprise/mariadb-enterprise-operator/updates/update-26.06.7) to ensure a safe transition.

### Changelog

* __K8SDKR-346__: New MaxScale servers are now always linked to the monitor. When a MaxScale Pod initialization was interrupted right after the server was created, for example by a client timeout on the MaxScale API, the server stayed registered in the routers but outside the monitor: it remained `Down`, MaxScale never became ready and the pending update of the `MariaDB` was blocked. The operator now reconciles the monitor whenever the servers change, which also recovers the MaxScale instances already left in this state.
