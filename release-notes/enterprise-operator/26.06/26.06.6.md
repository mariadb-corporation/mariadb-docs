# MariaDB Enterprise Kubernetes Operator 26.06.6

**Release date**: 16 October 2026

MariaDB Enterprise Kubernetes Operator 26.06.6 is a maintenance release for the 26.06 series. It fixes a hang when creating a replication topology with semi-synchronous replication enabled.

If you are updating from a previous version, **please follow the** [**UPDATE GUIDE**](https://mariadb.com/docs/tools/enterprise/mariadb-enterprise-operator/updates/update-26.06.6) to ensure a safe transition.

### Changelog

* __K8SDKR-339__: Creating a replication topology with semi-synchronous replication enabled no longer hangs when `spec.replication.semiSyncAckTimeout` is high. The operator now waits for the primary Pod to be assigned its role before configuring replication, so the replication user is created on the primary before semi-synchronous replication is armed and the replicas can authenticate.
