# MariaDB Enterprise Kubernetes Operator 26.06.9 Release Notes

MariaDB Enterprise Kubernetes Operator 26.06.9 is a security maintenance release of the 26.06 line, released on 2026-11-19.

**Release Date**: 19 November 2026

Release 26.06.9 is a maintenance release.

This document describes the changes in release 26.06.9, when compared to release 26.06.8.

{% hint style="info" %}
**This release only contains security fixes.** It fixes the Critical and High CVEs listed below in the operator image, and contains no functional or breaking changes.
{% endhint %}

If you are updating from a previous version, **please follow the** [**UPDATE GUIDE**](https://mariadb.com/docs/tools/enterprise/mariadb-enterprise-operator/updates/update-26.06.9) to ensure a safe transition.

## Security Fixes

The operator image `docker.mariadb.com/mariadb-enterprise-operator:26.6.9` is built with Go `1.27.4` and updates `github.com/klauspost/compress` to `v1.20.2`, `github.com/cert-manager/cert-manager` to `v1.20.3` and `golang.org/x/net` to `v0.62.0`. This fixes the following Critical and High CVEs reported against the `26.6.8` image:

* Go standard library, fixed by Go `1.27.4`:
  * [CVE-2026-78663](https://www.cve.org/CVERecord?id=CVE-2026-78663) (Critical): HTTP/2 server flow control in `net/http`.
  * [CVE-2026-78659](https://www.cve.org/CVERecord?id=CVE-2026-78659), [CVE-2026-78660](https://www.cve.org/CVERecord?id=CVE-2026-78660), [CVE-2026-78669](https://www.cve.org/CVERecord?id=CVE-2026-78669), [CVE-2026-97032](https://www.cve.org/CVERecord?id=CVE-2026-97032) (High): HTTP/2 in `net/http`.
  * [CVE-2026-94439](https://www.cve.org/CVERecord?id=CVE-2026-94439), [CVE-2026-56866](https://www.cve.org/CVERecord?id=CVE-2026-56866) (High): HTTP/1 `CONNECT` desynchronization in `net/http`.
  * [CVE-2026-97031](https://www.cve.org/CVERecord?id=CVE-2026-97031) (High): ECH handling in `crypto/tls`.
  * [CVE-2026-94440](https://www.cve.org/CVERecord?id=CVE-2026-94440) (High): MIME header memory limit in `net/textproto`.
  * [CVE-2026-78667](https://www.cve.org/CVERecord?id=CVE-2026-78667) (High): `Range` header parsing in `net/http`.
* [CVE-2026-63209](https://www.cve.org/CVERecord?id=CVE-2026-63209) (High): `github.com/klauspost/compress`, fixed by `v1.20.2`.
* [CVE-2026-62290](https://www.cve.org/CVERecord?id=CVE-2026-62290) (High): `github.com/cert-manager/cert-manager`, fixed by `v1.20.3`.
* The following findings do not affect the operator, and are no longer reported against the `26.6.9` image:
  * [CVE-2026-56857](https://www.cve.org/CVERecord?id=CVE-2026-56857) (Critical): `os.Root` on Windows. The operator image is Linux-only.
  * [CVE-2026-94444](https://www.cve.org/CVERecord?id=CVE-2026-94444), [CVE-2026-94447](https://www.cve.org/CVERecord?id=CVE-2026-94447) (High): the `cmd/go` build tool, which is not part of the operator image.

The [data-plane](https://mariadb.com/docs/tools/enterprise/mariadb-enterprise-operator/topologies/data-plane) containers run the operator image, so these CVEs are fixed in them once the data-plane is updated to `26.6.9`. Refer to the [update guide](https://mariadb.com/docs/tools/enterprise/mariadb-enterprise-operator/updates/update-26.06.9).
