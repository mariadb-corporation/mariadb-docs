# MariaDB Enterprise Kubernetes Operator 26.06.5

**Release date**: 15 October 2026

MariaDB Enterprise Kubernetes Operator 26.06.5 is a maintenance release for the 26.06 series. It fixes the scale-out of replication topologies managed by MaxScale when `gtidStrictMode` is enabled.

If you are updating from a previous version, **please follow the** [**UPDATE GUIDE**](https://mariadb.com/docs/tools/enterprise/mariadb-enterprise-operator/updates/update-26.06.5) to ensure a safe transition.

### Changelog

* __K8SDKR-337__: Scaling out a replication topology managed by MaxScale no longer fails with `Error 1950` when `gtidStrictMode` is enabled. New replicas are now registered in MaxScale only after the operator has configured replication on them, so MaxScale no longer starts replication on a new replica before the operator does.

### Platform and component versions

The current release has been tested with the following versions:

| Platform/Component        | Version    |
| ------------------------- | ---------- |
| Kubernetes                | 1.36       |
| OpenShift                 | 4.20       |
| MariaDB Enterprise Server | 11.8.8-5   |
| MaxScale                  | 25.10.4    |
