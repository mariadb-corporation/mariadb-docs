# Connector/Python 1.1.15 Release Notes

<a href="https://mariadb.com/downloads/connectors/connectors-data-access/python-connector/" class="button primary">Download</a> <a href="1.1.15.md" class="button secondary">Release Notes</a> <a href="../changelogs/1.1/1.1.15.md" class="button secondary">Changelog</a> <a href="https://app.gitbook.com/s/CjGYMsT2MVP4nd3IyW2L/connectors-quickstart-guides/connector-python-guide" class="button secondary">Connector/Python Overview</a>

**Release date:** 13 Oct 2026

This is a [_**stable**_](../../../community-server/about/release-criteria.md) release of MariaDB Connector/Python.

**For a description of this library see the** [**MariaDB Connector/Python documentation**](https://mariadb-corporation.github.io/mariadb-connector-python/index.html) **.**

MariaDB Connector/Python enables python programs to access MariaDB and MySQL databases, using an API which is compliant with the Python DB API 2.0 (PEP-249). It is written in C and uses MariaDB Connector/C client library for client server communication.

## Notable changes

* Python 3.15 Windows binary wheels
* removed support for Python 3.9 and 3.10 (eol)

## Bug fixes

* CONPY-317: build fixes
* CONPY-328: Fix conversion of signed one byte numbers (tinyint) in binary protocol.
* CONPY-331: name the argument when a connection keyword has the wrong type
* CONPY-332: make the ConnectionPool docstring raw to keep its Markdown escapes
* CONPY-334: Parser fixes
* CONPY-347: fix memory leak when raising MariaDB exceptions
* CONPY-364: close() is a no-op on a closed or finalized connection
* CONPY-365: release the GIL and set a value when a decimal length is invalid
* CONPY-368: return None for DATE/DATETIME values Python cannot represent
* CONPY-369: avoid connection segfaults during GC sweeps and deallocation
* CONPY-371: Fix leak in converter
* CONPY-376: connect() ignores connection arguments of an existing pool
* CONPY-382: Raise exception instead of crashing on a parameter that cannot be serialized
* CONPY-386: named_tuple: rename a column the row type cannot carry instead of refusing the result set
* CONPY-395: Binary cursor misclassifies a failed mysql_stmt_fetch() as a successful row
* CONPY-397: build the release against MariaDB Connector/C 3.4.11
* CONPY-399: status_callback borrowed reference causes use-after-free and refcount underflow

## Installation

MariaDB Connector/Python 1.1.15 can be obtained from central python repository:

```bash
pip3 install mariadb
```

or to upgrade to the most recent version

```bash
pip3 install --upgrade mariadb
```
