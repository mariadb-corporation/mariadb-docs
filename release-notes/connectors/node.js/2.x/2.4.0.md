# Connector/Node.js 2.4.0 Release Notes

{% include "../../../.gitbook/includes/latest-nodejs.md" %}

**Release date:** 26 May 2020

MariaDB Connector/Node.js 2.4.0 is a [_**Stable**_](../../../community-server/about/release-criteria.md) _**(GA)**_ release.

{% hint style="success" %}
**For an overview of MariaDB Connector/Node.js see the** [**About MariaDB Connector/Node.js**](https://app.gitbook.com/s/CjGYMsT2MVP4nd3IyW2L/mariadb-connector-nodejs/mariadb-connector-node-js-guide) **page**
{% endhint %}

This version removes compatibility with Node.js 6, needing 10+ version!

* [CONJS-86](https://jira.mariadb.org/browse/CONJS-86) - Support extension type format
* [CONJS-128](https://jira.mariadb.org/browse/CONJS-128) - Error when using multipleStatements with metaAsArray
* [CONJS-129](https://jira.mariadb.org/browse/CONJS-129) - Support 10.5 pluggable type
* [CONJS-131](https://jira.mariadb.org/browse/CONJS-131) - checkDuplicate option is indicated in error when having duplicate
* [CONJS-132](https://jira.mariadb.org/browse/CONJS-132) - performance improvement
* [CONJS-136](https://jira.mariadb.org/browse/CONJS-136) - typescript SqlError interface
