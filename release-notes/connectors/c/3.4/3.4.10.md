# Connector/C 3.4.10 Release Notes

**Release date:** xx Aug 2026

This is a [_**Stable (GA)**_](../../../community-server/about/release-criteria.md) release of MariaDB Connector/C, formerly known as MariaDB Client Library for C.

{% hint style="info" %}
**For a description of this library see the** [**MariaDB Connector/C**](https://app.gitbook.com/s/CjGYMsT2MVP4nd3IyW2L/mariadb-connector-c) **page.**

## Notable Items

* Included in MariaDB Community Server [11.4.13](../../../community-server/11.4/11.4.13.md), [11.8.9](../../../community-server/11.8/11.8.9.md) and [12.3.3](../../../community-server/12.3/12.3.3.md)
* Enable schannel async, unify synchronous and asynchronous IO

## Issues Fixed

* [CONC-813](https://jira.mariadb.org/browse/CONC-813),
* [CONC-814](https://jira.mariadb.org/browse/CONC-814): Fix Ubsan errors (Thanks to Michael Schorm for contribution)
* [CONC-817](https://jira.mariadb.org/browse/CONC-817): Cmake cleanup (Thanks to Michael Schorm for contribution)
* [CONC-818](https://jira.mariadb.org/browse/CONC-818): report CR_SERVER_LOST on TLS connection close (Thanks to Michael Schorm for contribution)
* [CONC-820](https://jira.mariadb.org/browse/CONC-820): Clamp server-provided field lengths to maximum bounds (reported by fg0x0)
* [CONC-825](https://jira.mariadb.org/browse/CONC-825): Fix unaligned pointer cast in int2store macro
* [CONC-826](https://jira.mariadb.org/browse/CONC-826): don't revalidate certificate after COM_CHANGE_USER
* [CONC-827](https://jira.mariadb.org/browse/CONC-827),[CONC-829](https://jira.mariadb.org/browse/CONC-829): Fix overflows and bugs identified by rpl_fuzzer
* [CONC-828](https://jira.mariadb.org/browse/CONC-828): Remove pvio blocking/is_blocking methods, always use non-blocking sockets
* [CONC-830](https://jira.mariadb.org/browse/CONC-830): Add MARIADB_CLIENT_PLUGIN_EXPORT for zstd compression plugin
* [CONC-834](https://jira.mariadb.org/browse/CONC-834): Fix poll timeout reset loop on EINTR signals (Thanks to Shaohua Wang for contribution)
* [CONC-835](https://jira.mariadb.org/browse/CONC-835): Fix pre-auth memory exhaustion in packet reassembly
* [CONC-838](https://jira.mariadb.org/browse/CONC-838): Fix PBKDF2 CPU stall vulnerability in parsec auth plugin
* [CONC-840](https://jira.mariadb.org/browse/CONC-840): Maxmimum number of result set columns is now limited up to 0xFFFFF (1048575) columns
* [CONC-841](https://jira.mariadb.org/browse/CONC-841): Added support for MYSQL_VECTOR field type (ps protocol)
* [CONC-842](https://jira.mariadb.org/browse/CONC-842): Fix heap buffer over-read in mthd_my_read_rows
* [CONC-843](https://jira.mariadb.org/browse/CONC-843): Throw error for unknown field types (MYSQL_VECTOR) instead of crashing
* [CONC-844](https://jira.mariadb.org/browse/CONC-844): OOB read and integer underflow in init_read_hdr() via untrusted dynamic column header
* [CONC-846](https://jira.mariadb.org/browse/CONC-846): Auth-switch allows cleartext password leakage on TLS hostname verification failure
* [CONC-847](https://jira.mariadb.org/browse/CONC-847): Fix OOB read in unpack_fields() on truncated metadata packet
