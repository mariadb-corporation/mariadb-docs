## Notable Items

* [CONC-852](https://jira.mariadb.org/browse/CONC-852): Load CRLs from ssl_crl directory (GnuTLS)
* Added new API function mariadb_net_field_length

## Issues Fixed

* [CONC-858](https://jira.mariadb.org/browse/CONC-858): Fix integer overflows when decoding dynamic columns
* [CONC-859](https://jira.mariadb.org/browse/CONC-859): Fix out-of-bounds heap read in get_compression_info()
* [CONC-861](https://jira.mariadb.org/browse/CONC-861): Bound checks for length encoded integers and binary rows
* [CONC-863](https://jira.mariadb.org/browse/CONC-863): Check that name offsets of dynamic columns do not decrease
* [CONC-864](https://jira.mariadb.org/browse/CONC-864): Fix memory leak in mariadb_dyncol_list_named()
* [CONC-868](https://jira.mariadb.org/browse/CONC-868): Fix out-of-bounds read in my_uca1400_collation_id_uca400_compat()
* [CONC-869](https://jira.mariadb.org/browse/CONC-869): Fix OOB read in dyncol value readers due to unvalidated interval lengths
* [CONC-870](https://jira.mariadb.org/browse/CONC-870): Fix stack buffer overflow in ma_fcvt
* [CONC-871](https://jira.mariadb.org/browse/CONC-871): Fix heap overflow in madb_alloc_stmt_fields
