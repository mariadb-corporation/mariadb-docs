# Connector/C 3.1.1 RC Release Notes

{% include "../../../.gitbook/includes/latest-c.md" %}

[Download](https://mariadb.com/downloads/connectors)[Release Notes](3.1.1.md)[Changelog](../changelogs/3.1/3.1.1.md)[About MariaDB Connector/C](https://app.gitbook.com/s/CjGYMsT2MVP4nd3IyW2L/mariadb-connector-c)

**Release date:** 6 Jun 2019

This is a [_**Release Candidate (RC)**_](../../../community-server/about/release-criteria.md) release of the MariaDB\
Connector/C, formerly known as MariaDB Client Library for C.

**For a description of this library see the**[**MariaDB Connector/C**](https://app.gitbook.com/s/CjGYMsT2MVP4nd3IyW2L/mariadb-connector-c) **page.**

## Bug fixes

* [CONC-416](https://jira.mariadb.org/browse/CONC-416): Changed order for lookup configuration files on Windows
* [CONC-386](https://jira.mariadb.org/browse/CONC-386): Added support for pem files which contain certificate and private key.
* [CONC-412](https://jira.mariadb.org/browse/CONC-412): Allow TLS version 1.2 when using SChannel (Windows)
