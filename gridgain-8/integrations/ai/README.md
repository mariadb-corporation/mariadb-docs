# AI Integration

GridGain 8 integrates with popular AI and LLM frameworks, including LangChain, LangGraph, Langflow, and Feast, using GridGain as a vector store, agent memory, and feature store.

- [LangChain Integration](langchain.md): Use GridGain as a backend for LangChain key-value stores, document loaders, chat history, LLM caches, and vector stores.
- [LangGraph Integration](langgraph.md): Use GridGain as a LangGraph checkpointer and long-term memory store.
- [Langflow Integration](langflow.md): Build low-code AI workflows with GridGain vector store and chat memory components in Langflow.
- [Feast Integration](feast.md): Use GridGain as an online feature store for Feast to serve features in real time.
- [MCP Server](mcp-server/README.md): Let AI assistants such as Claude Code, Cursor, and Visual Studio Code inspect a cluster and run read-only SQL queries.

{% hint style="info" %}
GridGain 8's native vector search capability is documented separately. See [Vector Search](../../gridgain8-development/vector-search/README.md).
{% endhint %}
