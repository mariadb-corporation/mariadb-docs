# Tutorials

Tutorials teach by doing: each one builds or operates something end to end on a local cluster. Use the reference sections of this documentation for complete configuration details, and use these tutorials to learn how the pieces fit together.

New to GridGain 8? Read [What Is GridGain?](../gridgain8-get-started/what-is-gridgain.md) and run the [Quick Start](../gridgain8-get-started/quick-start/README.md) first, then follow a learning path below.

## Learning Paths

| Path | Level | Start here when |
| ---- | ----- | --------------- |
| [Cache-Centric Foundations](cache-centric-foundations/README.md) | Beginner | You are new to GridGain 8 and want a guided first week. |
| [Beyond Key-Value](beyond-key-value/README.md) | Intermediate | Plain caching no longer covers your needs: SQL, transactions, compute, persistence, or events. |
| [Design for Data Locality](data-locality/README.md) | Advanced | You need predictable performance by keeping related data and compute together. |
