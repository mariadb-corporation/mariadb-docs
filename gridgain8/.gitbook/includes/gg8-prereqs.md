This section describes the platform requirements for machines running GridGain. GridGain system requirements scale depending on the size of the cluster.

| Requirement | Details |
| --- | --- |
| JDK | Oracle JDK 17 or later |
| OS | Linux (any flavor), Windows (10 and up). For Docker environment, we provide Linux docker containers. |
| ISA | x86-64, SPARC, PowerPC |
| Network | No restrictions (10G recommended) |
