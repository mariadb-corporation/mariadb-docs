# Security Vulnerabilities (CVE) Fixed in GridGain 8

This page contains a full list of CVEs fixed in all versions and series of GridGain 8.

The list is updated continuously. CVEs may be added retroactively to already-released versions, as vulnerabilities can be reported to and assigned by CVE Numbering Authorities (CNAs) after the corresponding fix has been released. As a result, a release may receive additional CVE entries over time even after it has been published.

A release can also fix vulnerabilities that do not yet have a CVE identifier. Advisories still awaiting an identifier appear in the release notes, and each is added here once a CVE identifier is assigned.
