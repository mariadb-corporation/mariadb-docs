# Quick Start Guide

This guide aims to get you started in minutes. It explains how to install GridGain, start a node, and run your first GridGain application in the preferred language.

We suggest that before you dive into developing applications in GridGain, you might want to just run a quick `Hello, world!` program in your desired language, or maybe use SQL on the command line to create a table and load a few rows.

The examples in this section cover a basic installation and node start, followed by a short code-specific example.
