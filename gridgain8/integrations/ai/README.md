# AI Integration

GridGain 8 integrates with popular AI and LLM frameworks, including LangChain, Langflow, and Feast, using GridGain as a vector store and feature store.

- [LangChain Integration](langchain.md): Use GridGain as a backend for LangChain key-value stores, document loaders, chat history, LLM caches, and vector stores.
- [Langflow Integration](langflow.md): Build low-code AI workflows with GridGain vector store and chat memory components in Langflow.
- [Feast Integration](feast.md): Use GridGain as an online feature store for Feast to serve features in real time.

{% hint style="info" %}
GridGain 8's native vector search capability is documented separately. See [Vector Search](../../gridgain8-usage/vector-search/README.md).
{% endhint %}
