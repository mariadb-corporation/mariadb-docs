# ODBC Driver

GridGain includes an ODBC driver that lets you both query and modify data stored in a distributed cache using standard SQL queries and the native ODBC API.

The pages in this section explain how to build, install, and use the driver:

- [ODBC Driver](odbc-driver.md) — overview, cluster configuration, and how to build and install the driver.
- [Connection String and DSN](connection-string-dsn.md) — connection string format, supported arguments, and DSN configuration.
- [Data Types](data-types.md) — the SQL data types supported by the driver.
- [Querying and Modifying Data](querying-modifying-data.md) — connecting to a cluster and running SQL queries through ODBC.
- [Error Codes](error-codes.md) — the error codes returned by the driver.
- [Specification](specification.md) — ODBC interface conformance levels and supported features.
