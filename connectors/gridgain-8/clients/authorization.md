# Client Authorization

You can configure thin client authorization in the cluster. Refer to the [Authorization](https://www.gridgain.com/docs/gridgain8/latest/administrators-guide/security/authorization-permissions) page for details.

{% hint style="info" %}
Server side authorization is available in GridGain Enterprise and GridGain Ultimate Editions only.
{% endhint %}
