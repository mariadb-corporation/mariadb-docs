## Installation

### NuGet

NuGet is the most convenient way to include GridGain.NET into your project. The main package is `Apache.Ignite`, additional functionality is available in the following packages:

- `Apache.Ignite.Linq`
- `Apache.Ignite.Schema`
- `Apache.Ignite.NLog`
- `Apache.Ignite.Log4Net`
- `Apache.Ignite.AspNet`
- `Apache.Ignite.EntityFramework`

### Binary Distribution

The standard GridGain binary package includes .NET libraries.

1. Download the package from [GridGain downloads](https://www.gridgain.com/resources/download).
2. Unpack the archive into your chosen installation directory.
